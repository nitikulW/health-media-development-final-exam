   - บท10_การสร้างสื่อสุขภาพแบบภาพเคลื่อนไหว_2_มิติ_1_Animaker.md
   - บท11_การสร้างสื่อสุขภาพแบบภาพเคลื่อนไหว_2_มิติ_2_Synfig.md

   💡 เคล็ดลับสำคัญเพื่อให้ AI พูดครบทุกหัวข้อโดยไม่ข้ามรายละเอียด:

--------------------------------------------------------------------------------
พูดสรุปเนื้อหาเป็นภาษาไทยแบบละเอียดที่สุด ครบทุกบทและทุกหัวข้อเรียงตามลำดับในเอกสาร ตั้งแต่ต้นจนจบเหมือนอ่านทบทวนหน้าเว็บติวสอบปลายภาควิชา 553127-168 การพัฒนาสื่อสุขภาพ (48 ข้อ 48 คะแนน) ห้ามข้ามหัวข้อย่อยใดๆ เด็ดขาด โดยต้องพูดให้ครบทั้ง 4 ตอนดังนี้:
1. ตอนที่ 1 (คาบ 8-9 แดชบอร์ดข้อมูลสุขภาพ 16 ข้อ): อธิบายความหมาย Data Visualization กับ Dashboard, ประโยชน์จากงานวิจัย 4 ข้อ, เปรียบเทียบ Google Data Studio (Looker Studio) vs Power BI vs Tableau, การเลือกใช้ Google Sheets (Dynamic) vs MS Excel (Static), Freeform vs Responsive Layout, ความแตกต่างของ Dimension (สีเขียว ABC) vs Metric (สีน้ำเงิน 123 ค่าเริ่มต้น Sum และการปรับเป็น AVG ที่ Aggregation), การตั้งค่า Scorecard + Filter, Pie Chart + Optional metrics + Add Group + Drill Down, Google Maps (Location, Size, Color metric), Bar Chart + Breakdown Dimension, Time Series (รูปแบบวันที่ 2026-01 และ 2026-01-01, ข้อควรระวัง Comparison date range กับ Breakdown Dimension, Trendline, Reference Line), ตัวควบคุม Controls ทั้ง 6 ชนิด (Drop-down, Input box แบบ Equals/Contains/Starts with, Slider, Dimension control, Date range control, Button), ขั้นตอน Reconnect 6 ขั้นเมื่อเพิ่มคอลัมน์ใน Sheet, การทำ Blend Data (สูงสุด 5 ตาราง) และ Join Operators ทั้ง 5 แบบ (Inner, Left Outer, Right Outer, Full Outer, Cross Join) พร้อมกรณีศึกษาเชื่อม 3 ตารางด้วยรหัสพนักงานและรหัสยา, การซ่อน Navigation (Hidden) และการแชร์ 5 วิธี
2. ตอนที่ 2 (คาบ 10 Animaker 8 ข้อ): เว็บสร้างแอนิเมชัน 6 แห่ง, ระดับสมาชิกและพื้นที่ฟรี 2 GB, สัดส่วนวิดีโอ (16:9, 1:1, 9:16), การเปลี่ยนสีพื้นหลัง Gradient + Direction, การสร้างฉากหลังด้วย AI (Prompt + Color + Visual Style), การใส่ Animation ข้อความ (Enter/Exit), การสร้างตัวละคร (Create your own character), Action, Expression, ขั้นตอนการใช้ ActionPlus และ Edit/Replace, การใส่เสียงพากย์ 3 วิธี (Record, Text to Speech, Upload), การลดเสียงเพลงด้วย Advanced Edit (ดึงเส้นตรงลง), Smart move, Camera Timeline (Static vs Dynamic Camera), Transition effect, และข้อจำกัด Free user (Publish Download Video ไม่เกิน 2 นาที vs Share ลิงก์ได้ไม่จำกัดความยาว)
3. ตอนที่ 3 (คาบ 11 Synfig Studio 8 ข้อ): คุณสมบัติ Synfig 1.4.5 (Freeware, Vector & Bitmap, Linux/Mac/Windows, ใช้ทรัพยากรต่ำ), ค่า Z Depth (ค่าน้อยอยู่บนสุด ค่ามากอยู่ล่างสุด), การย้ายสี่เหลี่ยมต้องคลิกขวา Group Layer ก่อน, หน้าที่ของจุดควบคุมทั้ง 7 สี (เขียว น้ำเงิน ส้ม เหลืองบน เหลืองขวา แดง เทา), โหมด Turn on animate editing mode, รูปแบบการเคลื่อนที่ 5 แบบ (Clamped สีส้ม, TCB สีเขียวที่มีข้อเสีย Overshoot, Constant สีแดงสำหรับตากะพริบ/ปากพูด, Ease In/Out สีน้ำเงิน, Linear สีเหลือง), ไฟล์ .sifz และการ Render 3 แบบ (.avi Target Auto, .gif Target gif, .png Target png + Render current frame only), การกลับด้านภาพด้วยเครื่องหมายลบหน้า Scale แกน X แล้วกด Enter 2 ครั้ง, ความแตกต่างระหว่าง Waypoint กับ Keyframe (จดจำสถานะทุกเลเยอร์), การทำตัวละครพูดด้วย Group Layers into Switch (Active Layer Name), การสร้างกระดูก Skeleton (Parent bone แกนกลาง, Child bone ลำตัว/หัว/แขน ส่วนขาแยกจากแกนกลางโดยตรง, และการผูก Link to Bone), และการทำเดินวนลูปด้วย Time Loop (ลบ Waypoint ของ Offset แล้วตั้ง Duration = 31f)
4. ตอนที่ 4 (คาบ 12-13 WordPress.org 16 ข้อ): สถิติอินเทอร์เน็ตและมือถือ (75% ตัดสินความน่าเชื่อถือจากเว็บดีไซน์, มือถือ 50.38%, หมวดสุขภาพ 68%, 53% ออกจากเว็บมือถือที่โหลดเกิน 3 วินาที), องค์ประกอบสร้างเว็บ 3 ส่วน, วิธีสร้างเว็บ 3 วิธี, ส่วนแบ่งตลาด CMS (WordPress อันดับ 1 คือ 43.3% ของเว็บทั้งหมด / 60.7% ของ CMS, Joomla 1.4%, Drupal 0.8% แต่นิยมในเว็บใหญ่ 6-7%), Responsive Design, ข้อจำกัด Free Hosting, สเปก AwardSpace (1 GiB = 1024^3 bytes vs 1 GB = 1000^3 bytes), กฎการตั้งชื่อ Domain Name 3 ข้อ, ประวัติ WordPress (27/05/2003, PHP + MySQL/MariaDB), เปรียบเทียบ WordPress.org vs WordPress.com, การติดตั้งด้วย Zacky App Installer, URL หน้าบ้าน vs หลังบ้าน (/wp-admin/), ตั้งเวลา UTC+7, การลง Theme, Site Identity (Site Icon 512x512 px), เปรียบเทียบ Post vs Page, การทำเมนูย่อย (ลากเยื้องไปทางขวา), การทำหน้าแรกด้วยบล็อก Query Loop (กรอง Filters -> Taxonomies -> Tags) + ตั้งค่า Homepage Settings เป็น A static page, การจัดการ Widgets และการลบ Plugins 2 ขั้นตอน (Deactivate แล้วค่อย Delete)

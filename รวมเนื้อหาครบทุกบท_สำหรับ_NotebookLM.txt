## ส่วนที่ 1: แนวคิดพื้นฐานของ Data Visualization และ Dashboard (CLO1, CLO3) ⭐⭐⭐

### 1.1 ปัญหาของการจัดการข้อมูลแบบดั้งเดิม (สไลด์หน้า 2) ⭐⭐
- ปัจจุบันองค์กรด้านสุขภาพมีการจัดเก็บข้อมูลในหลายรูปแบบ ทั้ง **เอกสารกระดาษ**, **ไฟล์ดิจิทัล** (เช่น Microsoft Word, Excel) รวมถึง **ฐานข้อมูลส่วนตัวหรือฐานข้อมูลขององค์กร**
- **ปัญหาที่พบ**:
  1. เกิดความกระจัดกระจายของข้อมูล และมีความยุ่งยากในการรวบรวม วิเคราะห์ และนำข้อมูลมาใช้ประโยชน์
  2. ข้อมูลที่อยู่ในรูปแบบ **ตัวเลขหรือข้อความดิบ** ทำให้มองเห็นแนวโน้มของสถานการณ์ได้ยาก และก่อให้เกิดความคลาดเคลื่อนในการวิเคราะห์หรือคาดการณ์ผลลัพธ์

### 1.2 ความหมายของแผนภาพข้อมูล (Data Visualization) และแดชบอร์ด (Dashboard) (สไลด์หน้า 3–4) ⭐⭐⭐
- **แผนภาพข้อมูล (Data Visualization)**:
  - คือ **กระบวนการแปลงข้อมูลเชิงตัวเลขหรือข้อความที่ซับซ้อนให้เป็นภาพที่เข้าใจง่าย**
  - ช่วยให้ผู้ใช้งานมองเห็น **แนวโน้ม (Trends)**, **ความสัมพันธ์ (Relationships)** และ **ข้อมูลสำคัญ** ได้อย่างรวดเร็วและแม่นยำ
  - ตัวอย่างรูปแบบแผนภาพ: กราฟแท่ง (Bar chart), กราฟเส้น (Line/Time series chart), แผนภูมิวงกลม (Pie chart), แผนภาพการกระจาย (Scatter plot)
- **แดชบอร์ด (Dashboard)**:
  - คือ **เครื่องมือในการนำเสนอข้อมูลโดยการรวมรายงาน กราฟ หรือดัชนีชี้วัดที่สำคัญ (KPIs) มาแสดงไว้ในหน้าจอเดียวกัน** เพื่อให้มองเห็นภาพรวมของข้อมูลในเรื่องที่ต้องการได้อย่างรวดเร็วและชัดเจน
  - **ประโยชน์ของแดชบอร์ดตามงานวิจัย (สไลด์หน้า 4 — ออกสอบเน้น!)**:
    1. **ลดระยะเวลา**ในการรวบรวมและวิเคราะห์ข้อมูล
    2. **ลดภาระทางความคิด (Cognitive Load)** ของผู้ใช้งาน
    3. **ลดความผิดพลาด**ในการแปลผลข้อมูล
    4. **เพิ่มความสามารถในการรับรู้สถานการณ์ (Situation Awareness)**

## ส่วนที่ 2: เปรียบเทียบเครื่องมือสร้าง Dashboard และแหล่งเก็บข้อมูล (CLO1, CLO3) ⭐⭐⭐

### 2.1 เปรียบเทียบ 3 เครื่องมือสร้าง Interactive Dashboard ยอดนิยม (สไลด์หน้า 5–14) ⭐⭐⭐
เครื่องมือสร้างแดชบอร์ดแบบโต้ตอบ (**Interactive Dashboard** ที่ผู้ใช้งานปรับแต่งมุมมองข้อมูลได้ตามความต้องการ) ที่ได้รับความนิยมมี 3 ตัวหลัก ได้แก่:

| เครื่องมือ | จุดเด่นและกลุ่มเป้าหมาย | แหล่งข้อมูลที่เชื่อมต่อได้ | ข้อจำกัดสำคัญ (ระวังออกสอบ!) |
| :--- | :--- | :--- | :--- |
| **1. Google Data Studio** *(ชื่อเดิมคือ Google Looker Studio / ปัจจุบันเรียกสลับกัน)* | - **เหมาะสำหรับผู้เริ่มต้นใช้งาน** และ **ธุรกิจขนาดเล็กถึงขนาดกลาง**<br>- ปรับแต่งง่าย **ใช้งานได้ฟรี**<br>- แชร์และทำงานร่วมกันแบบเรียลไทม์ผ่านบัญชี Google ได้สะดวก | ผลิตภัณฑ์ของ Google (Google Analytics, Google Sheets, AppSheet, BigQuery, Google Ads) รวมถึง Microsoft Excel, Facebook, Twitter, MySQL database (มี Connector กว่า 1,040 รายการ) | **ยังไม่สามารถวิเคราะห์ข้อมูลเชิงลึกได้ดีเท่าเครื่องมือที่ต้องเสียค่าใช้จ่าย** |
| **2. Microsoft Power BI** | - **เหมาะสำหรับการใช้งานในองค์กรที่ต้องการการวิเคราะห์ข้อมูลเชิงลึก**<br>- มีฟีเจอร์การอัปเดตข้อมูลอัตโนมัติ และการสร้างแดชบอร์ดแบบเรียลไทม์ | Excel, Text, Hadoop, Google Analytics และฐานข้อมูลองค์กรหลากหลาย | **การแชร์แดชบอร์ดหรือรายงานให้ผู้อื่นเข้าถึงได้ จำเป็นต้องสมัครใช้งานแบบเสียค่าใช้จ่ายรายเดือนหรือรายปี** |
| **3. Tableau** | - เน้น **ความง่ายในการใช้งานควบคู่ไปกับความยืดหยุ่นสูง**<br>- มีความสามารถในการวิเคราะห์เชิงลึก เหมาะกับงานที่ต้องจัดการ **ข้อมูลจำนวนมากและซับซ้อน (Big Data)** | Google Sheets, MySQL รวมถึงฐานข้อมูลขนาดใหญ่ | **มีค่าใช้จ่ายใบอนุญาตสูง** จึงมักถูกเลือกใช้โดย **องค์กรขนาดกลางถึงขนาดใหญ่ที่มีงบประมาณเพียงพอ** |

> [!IMPORTANT]
> **สรุปการเปรียบเทียบ Tableau VS Google Data Studio (สไลด์หน้า 13)**:
> - **Tableau**: มีประสิทธิภาพเหนือกว่าในบริบทของ **ข้อมูลขนาดใหญ่** และสภาพแวดล้อมที่ต้องการ **ความยืดหยุ่นในการวิเคราะห์ขั้นสูง**
> - **Google Data Studio**: เหมาะสำหรับ **ธุรกิจขนาดเล็กถึงขนาดกลาง** เพราะ **ใช้งานฟรี**, ทำงานร่วมกันง่าย และแชร์แบบเรียลไทม์ผ่านบัญชี Google

### 2.2 การเลือกใช้ Google Sheets VS Microsoft Excel เป็นแหล่งข้อมูล (สไลด์หน้า 15–18) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | Google Sheets | Microsoft Excel |
| :--- | :--- | :--- |
| **ลักษณะข้อมูลที่เหมาะสม** | ข้อมูลที่มีการเคลื่อนไหวตลอดเวลา (**Dynamic**) | ข้อมูลแบบสรุปที่นิ่งแล้ว (**Static**) |
| **ความต้องการด้านการใช้งาน** | ต้องการให้ **Dashboard อัปเดตข้อมูลได้เองอัตโนมัติ** | ต้องการใช้ **ฟังก์ชันของ Excel ในการคำนวณหรือจัดโครงสร้างข้อมูลที่ซับซ้อน** ก่อนนำเสนอ |
| **ตัวอย่างการนำไปใช้** | ข้อมูลจากฟอร์มลงทะเบียน, ตัวชี้วัดที่ต้องติดตามทุกวัน | รายงานสรุปผลประกอบการประจำเดือน, สรุปผลประเมินรายไตรมาสที่ข้อมูลนิ่งแล้ว |

- **ช่องทางยอดนิยม 4 วิธีในการเตรียมข้อมูลเข้าสู่ Google Data Studio (สไลด์หน้า 18)**:
  1. สร้าง **Google Form** เพื่อใช้ในการเก็บข้อมูล
  2. นำข้อมูลมาจาก **Microsoft Excel** → แปลงเป็น **Google Sheet** เก็บไว้ใน Google Drive
  3. สร้าง Application ในการเก็บ/รับข้อมูล เช่น **AppSheet**
  4. นำข้อมูลมาจาก **Google Sheet** โดยตรง
  - **ข้อสังเกตสำคัญ**: **ทั้ง 4 วิธีข้างต้นจะทำให้ได้ข้อมูลที่เก็บอยู่ในรูปของ Google Sheet ทั้งสิ้น**

## ส่วนที่ 3: การเริ่มต้นใช้งาน โครงสร้างหน้าจอ และการจัดวาง Layout (CLO1, CLO3, CLO4) ⭐⭐⭐

### 3.1 ขั้นตอนการเริ่มสร้างรายงานและเชื่อมต่อ Google Sheets ครั้งแรก (สไลด์หน้า 19–25) ⭐⭐
1. เข้าเว็บไซต์ `https://datastudio.google.com/` → คลิกปุ่ม **`Create a report`** (กรณีสมัครใช้งานใหม่ ระบบจะให้กรอกข้อมูลเบื้องต้นก่อน)
2. ปรากฏหน้าต่าง **`Add data to report`** → เลือก Connector **`Google Sheets`**
3. **ในการเชื่อมต่อกับ Google Sheets ครั้งแรก**: ต้องคลิกปุ่ม **`Authorize`** เพื่อให้ Data Studio ได้รับสิทธิ์เชื่อมต่อกับ Google Sheets
4. เลือกไฟล์ Google Sheet (Spreadsheet) และแผ่นงาน (Worksheet) ที่เป็นฐานข้อมูล → คลิก **`Add`**

### 3.2 เปรียบเทียบการจัดวางหน้ากระดาษ: Freeform Layout VS Responsive Layout (สไลด์หน้า 26–27) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | Freeform Layout (การจัดวางแบบอิสระ) | Responsive Layout (การจัดวางแบบปรับตามหน้าจอ) |
| :--- | :--- | :--- |
| **การวางองค์ประกอบและซ้อนทับ** | ลากและวางกราฟ ตาราง หรือข้อความไว้ **ตำแหน่งใดก็ได้ตามต้องการ** และ **สามารถวางองค์ประกอบซ้อนทับกันได้** | **ไม่สามารถวางองค์ประกอบซ้อนทับกันได้อย่างอิสระ** |
| **การแสดงผลบนหน้าจอขนาดต่างๆ** | ขนาดและตำแหน่งถูกจัดไว้ **ตายตัว (Fixed)** หากเปิดดูในหน้าจอที่เล็กกว่าที่ออกแบบไว้ **จะต้องเลื่อนแถบ Scroll bar หรือขยายเพื่อดูข้อมูล** | องค์ประกอบต่างๆ จะถูก **ปรับให้พอดีกับขนาดความกว้างของหน้าจออุปกรณ์ที่กำลังเปิดดูโดยอัตโนมัติ** |
| **การใช้งานในปฏิบัติการ** | ในการเรียนปฏิบัติการจะเลือก **`Freeform Layout`** ซึ่งจะปรากฏเส้นตาราง (Grid) บนพื้นที่ทำงาน | เหมาะกับรายงานที่ต้องการให้ยืดหยุ่นตามหน้าจอมือถืออัตโนมัติโดยไม่มีการซ้อนทับ |

### 3.3 องค์ประกอบของหน้าจอบน Google Data Studio (สไลด์หน้า 28) ⭐⭐
1. **Main menu & Toolbar (แถบเมนูด้านบน)**: จัดการไฟล์ เพิ่มหน้า เพิ่มข้อมูล (`Add data`) เพิ่มแผนภูมิ (`Add a chart`) เพิ่มตัวควบคุม (`Add a control`) แทรกรูปภาพ ข้อความ รูปทรง
2. **Work area & Report (พื้นที่ตรงกลาง)**: พื้นที่ใช้ในการสร้างและจัดวางรายงานตามรูปแบบที่ต้องการ
3. **Data & Properties panel (แถบด้านขวา)**: ใช้จัดการข้อมูล (**แท็บ `Setup`**) และปรับแต่งรูปแบบการนำเสนอ/สี/ขนาด (**แท็บ `Style`**) รวมถึงรายการฟิลด์ข้อมูลในตาราง (**`Data`**)
4. **ปุ่ม `View / Edit` (มุมบนขวา)**: ใช้สลับระหว่างโหมดแก้ไขรายงาน (`Edit`) กับโหมดตรวจสอบการแสดงผลของ Dashboard เสมือนผู้ใช้งานจริง (`View` — สไลด์หน้า 36)

## ส่วนที่ 4: ความแตกต่างระหว่าง Dimension VS Metric (ออกสอบแน่นอน!) ⭐⭐⭐

### 4.1 ตารางเปรียบเทียบ Dimension กับ Metric (สไลด์หน้า 29–31) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | Dimension (มิติข้อมูล) | Metric (ค่าวัด / ตัวชี้วัด) |
| :--- | :--- | :--- |
| **ความหมาย** | **เกณฑ์ที่ใช้ในการแบ่งกลุ่ม จัดหมวดหมู่ หรือแยกแยะข้อมูลดิบออกเป็นส่วนๆ** เพื่อให้เห็นรายละเอียดในแต่ละแง่มุม (ในกราฟอนุกรมเวลามักเป็นแกนแนวนอน/แกน X) | **ตัวเลขที่แสดงปริมาณหรือขนาด** ของสิ่งที่เรากำลังสนใจวัดผลหรือคำนวณทางสถิติ (ในกราฟมักเป็นแกนแนวตั้ง/แกน Y) |
| **ประเภทข้อมูล** | **ข้อมูลเชิงคุณภาพ (Qualitative)** เช่น ข้อความ, วันที่และเวลา, สถานที่ | **ข้อมูลเชิงปริมาณ (Quantitative)** ประเภทตัวเลขที่ใช้คำนวณได้ |
| **สีและสัญลักษณ์ใน Data Studio** | แสดงเป็น **สีเขียว** (ไอคอน **`ABC`** สำหรับข้อความ, **ปฏิทิน** สำหรับวันที่, หรือ **ลูกโลก** สำหรับสถานที่) | แสดงเป็น **สีน้ำเงิน** (ไอคอน **`123`** หรือ `AUT`) |
| **ตัวอย่างจากตารางสินค้า (สไลด์หน้า 30)** | `Item Name` (Hat, Coat, Scarf), `Color` (Black, White, Red) | `Quantity Sold` (20, 25, 35, 10, 15) |
| **ตัวอย่างจากข้อมูลบุคลากรฝ่ายเภสัชกรรม** | `รหัสพนักงาน`, `ชื่อ-นามสกุล`, `เพศ`, `ตำแหน่ง`, `หน่วยงาน`, `ระดับการศึกษา`, `จังหวัดภูมิลำเนา` | `Record Count` (จำนวนคน), `เงินเดือน (บาท)`, `คะแนนประเมิน (100)`, `อายุ`, `อายุงาน (ปี)`, `ชั่วโมงอบรม (ปี)` |

## ส่วนที่ 5: การใส่องค์ประกอบพื้นฐานและแผนภูมิชนิดต่างๆ (Charts) (CLO3, CLO4) ⭐⭐⭐

### 5.1 รูปภาพ (Image), ข้อความ (Text) และรูปทรง (Shape) (สไลด์หน้า 33–44) ⭐⭐
- **การใส่รูปภาพ (`Image` → `Upload from computer`)**:
  - ตั้งค่าใน `Image Properties` (มี 2 แท็บคือ `Setup` และ `Style`)
  - **การทำรูปภาพเป็นปุ่มลิงก์**: ไปที่ `Image properties` → แท็บ **`Setup`** → ใส่ URL ในช่อง **`Insert Link`** (เช่น คลิกโลโก้แล้วเปิดเว็บไซต์คณะเภสัชศาสตร์)
- **การใส่ข้อความ (`Text`)**:
  - พิมพ์ข้อความแล้วปรับแต่งที่ `Text Properties` → หากต้องการเปลี่ยนสีพื้นหลังกล่องข้อความให้ไปที่ `Background and border` → `Background` (ในสไลด์แนะนำเว็บเลือกชุดสีพาสเทล `https://colorhunt.co/palettes/pastel`)
- **การใส่รูปทรง (`Shape`)**:
  - เลือกรูปทรงสี่เหลี่ยมหรือวงกลมเพื่อใช้เป็นกรอบพื้นหลังหรือแถบหัวข้อ (Header banner) แล้วปรับสี/ขอบเขตที่ `Shape Properties`

### 5.2 แผนภูมิ Scorecard และการกรองข้อมูลด้วย Filter (สไลด์หน้า 45–51) ⭐⭐⭐
- **Scorecard (ป้ายแสดงตัวเลขสรุปสำคัญ)**:
  - เพิ่มโดยคลิก `Add a chart` → เลือก **`Scorecard`**
  - ใช้แสดงตัวเลขสรุปค่าเดียวเด่นๆ เช่น **จำนวนบุคลากรทั้งหมด (`Record Count` = 40)**
- **การแสดงผลเฉพาะกลุ่มที่ต้องการด้วย `Filter` (สไลด์หน้า 49–51)**:
  - หากต้องการให้ Scorecard แสดงเฉพาะจำนวนบุคลากรในตำแหน่งใดตำแหน่งหนึ่ง (เช่น แสดงเฉพาะ `เภสัชกรชำนาญการ` = 6 คน หรือ `เภสัชกรปฏิบัติการ` = 12 คน) → ต้องไปที่แท็บ `Setup` ของ Scorecard แล้วคลิก **`Add a filter`**
  - **เงื่อนไขการสร้าง Filter**: ตั้งชื่อ Filter → เลือก **`Include`** → เลือกฟิลด์ **`ตำแหน่ง`** → เลือกเงื่อนไข **`Equal to (=)`** → กรอกค่า เช่น `เภสัชกรชำนาญการ` → คลิก `Save`

### 5.3 แผนภูมิวงกลม (Pie Chart), Optional Metrics, การจัดกลุ่ม (Add Group) และ Drill Down (สไลด์หน้า 52–73) ⭐⭐⭐
1. **การสร้าง Pie Chart พื้นฐาน**:
   - `Add a chart` → `Pie` → กำหนด **`Dimension`** = `หน่วยงาน` และ **`Metric`** = `Record Count` (แสดงสัดส่วนบุคลากรในแต่ละหน่วยงาน)
   - การเปลี่ยนสีชิ้นส่วนวงกลม: ไปที่แท็บ **`Style`** → หัวข้อ **`Color by`** เลือก **`Slice order`** (เลือกสีตามลำดับชิ้นส่วน) หรือ `Dimension values` และตั้งค่ารูปแบบตัวเลขบนชิ้นวงกลมได้ที่ **`Slice label`** (เช่น แสดงเป็น `%`, `Value`, หรือ `Label`)
2. **ฟีเจอร์ `Optional metrics` (สไลด์หน้า 54–58 — ออกสอบเน้น!)**:
   - **หน้าที่**: ช่วยให้ผู้เข้าชมรายงาน (**Viewer**) สามารถ **สลับเปลี่ยนค่าตัวเลข (Metric) ที่แสดงอยู่บนแผนภูมิได้เอง** (โดยคลิกที่ไอคอนกรวย/ตัวเลือก Metric มุมบนขวาของกราฟ)
   - **ข้อดี**: (1) **ประหยัดพื้นที่บนหน้าจอ** (ไม่ต้องสร้างกราฟหลายอัน) และ (2) **เพิ่มอิสระให้ผู้ใช้งานเลือกดูข้อมูลเฉพาะมุมมองที่สนใจ** (เช่น สลับดูระหว่าง `จำนวนบุคลากร (Record Count)` กับ `เงินเดือนรวม (เงินเดือน)`)
   - **การปรับรูปแบบการคำนวณของ Metric (`Aggregation` — สไลด์หน้า 56)**:
     - เมื่อลากฟิลด์ตัวเลขมาวางใน Metric ระบบจะตั้งค่าเริ่มต้นเป็น **ผลรวม (`Sum`)** ให้โดยอัตโนมัติ
     - ผู้ใช้สามารถคลิกที่รูปดินสอหน้าฟิลด์เพื่อเปลี่ยนชื่อที่แสดงในช่อง **`Display name`** และเปลี่ยนวิธีคำนวณทางสถิติที่หัวข้อ **`Aggregation`** เช่น **`Average (AVG)`** (ค่าเฉลี่ย), `Count`, `Min`, `Max`
3. **การจัดกลุ่มข้อมูลช่วงตัวเลขด้วย `Add Group` (สไลด์หน้า 63–67)**:
   - เมื่อต้องการทำแผนภูมิวงกลมแบ่ง **ช่วงอายุบุคลากร** (เช่น อายุน้อยกว่า 30 ปี, 30–40 ปี, มากกว่า 40 ปี):
   - ที่ช่อง **`Dimension`** คลิก **`Add Group`** → ตั้งชื่อกลุ่ม → เลือกฟิลด์ `อายุ` → กำหนดเงื่อนไขการแบ่งกลุ่ม → คลิก `Save`
   - **ความเชื่อมโยงระหว่างแผนภูมิ (Cross-filtering)**: แผนภูมิที่สร้างจากฐานข้อมูลเดียวกันในหน้าเดียวกันจะเชื่อมโยงกัน เมื่อคลิกเลือกชิ้นส่วนในแผนภูมิหนึ่ง อีกแผนภูมิจะกรองข้อมูลตามโดยอัตโนมัติ
4. **ฟีเจอร์ `Drill Down` (การเจาะลึกข้อมูลตามลำดับชั้น — สไลด์หน้า 68–73 — ออกสอบเน้น!)**:
   - **ความหมาย**: ฟังก์ชันที่ให้ผู้ใช้งานคลิกเพื่อดูรายละเอียดที่ซ่อนอยู่ได้ด้วยตัวเอง โดยเริ่มจากข้อมูลสรุปในภาพรวม แล้วเจาะดูรายละเอียดย่อยลึกลงไปเป็นชั้นๆ ตามหมวดหมู่ที่เตรียมไว้ เช่น **`ปี ➔ ไตรมาส ➔ เดือน ➔ วัน`** หรือ **`ภูมิภาค ➔ จังหวัด ➔ อำเภอ`** หรือ **`ตำแหน่ง ➔ ระดับการศึกษา`**
   - **ประโยชน์ของ Drill Down**:
     1. ช่วยให้ผู้บริหาร **ค้นหาที่มาของความผิดปกติในภาพรวมได้**
     2. **ลดความซับซ้อนของหน้าจอแสดงผล**
   - **วิธีตั้งค่าและการใช้งาน**:
     - ที่แท็บ `Setup` ส่วน **`Dimension`** → คลิกเปิดสวิตช์ **`Drill down`** → เพิ่มลำดับมิติข้อมูล (เช่น ชั้นที่ 1 `ตำแหน่ง`, ชั้นที่ 2 `ระดับการศึกษา`) และตั้ง `Metric` เป็น `คะแนนประเมิน (100)` แบบ **`AVG`**
     - บนแผนภูมิจะปรากฏ **ลูกศรขึ้น (`Drill up`)** และ **ลูกศรลง (`Drill down`)** เช่น เมื่อต้องการดูว่าในกลุ่ม *"เภสัชกรเชี่ยวชาญที่มีคะแนนประเมินเฉลี่ย 85.2"* เมื่อแบ่งแยกตามระดับการศึกษาแล้วแต่ละระดับได้คะแนนเฉลี่ยเท่าใด ให้คลิกที่กลุ่มเภสัชกรเชี่ยวชาญแล้วกดลูกศรลง (`Drill down`)

### 5.4 แผนที่ (Google Maps), แผนภูมิแท่ง (Bar Chart) และ Breakdown Dimension (สไลด์หน้า 74–91) ⭐⭐⭐
1. **การใส่แผนที่ (`Add a chart` → `Google Maps` — สไลด์หน้า 74–79)**:
   - ช่อง **`Location` (Dimension)**: เลือกฟิลด์สถานที่ เช่น **`จังหวัดภูมิลำเนา`**
   - ช่อง **`Size` (ขนาดวงกลมบนแผนที่)**: เลือกฟิลด์ **`Record Count`** (จังหวัดที่มีบุคลากรมาก วงกลมจะใหญ่)
   - ช่อง **`Color metric` (สีของวงกลมบนแผนที่)**: เลือกฟิลด์ **`คะแนนประเมิน (100)`** และปรับการคำนวณเป็น **`AVG`** (สีของจุดบนแผนที่จะไล่เฉดตามค่าเฉลี่ยคะแนนประเมินของจังหวัดนั้น)
2. **แผนภูมิแท่ง (`Bar Chart`) และ `Breakdown Dimension` (สไลด์หน้า 86–91 — ออกสอบเน้น!)**:
   - **`Breakdown Dimension` (มิติข้อมูลการแบ่งย่อย)**: ใช้สำหรับ **แตกย่อยข้อมูลในแผนภูมิออกเป็นกลุ่มย่อยโดยใช้สีเป็นตัวแบ่ง** ทำให้มองเห็นโครงสร้างหรือสัดส่วนที่ซ่อนอยู่ภายในแท่งข้อมูลนั้นๆ ได้
   - **ตัวอย่างในสไลด์หน้า 88**: ต้องการแสดงจำนวนบุคลากรแยกเพศชาย-หญิง ในแต่ละหน่วยงาน:
     - **Dimension (มิติข้อมูลหลัก / แกนหลัก)**: `หน่วยงาน`
     - **Breakdown Dimension (มิติข้อมูลการแบ่งย่อยด้วยสี)**: `เพศ`
     - **Metric (ตัวชี้วัด)**: `Record Count` (หรือ `คะแนนประเมิน` แบบ `AVG`)

### 5.5 ตาราง (`Table`) และแผนภูมิอนุกรมเวลา (`Time Series`) (สไลด์หน้า 92–96, 126–138) ⭐⭐⭐
1. **ตาราง (`Add a chart` → `Table` — สไลด์หน้า 92–96)**:
   - สามารถใส่ได้หลาย Dimension และหลาย Metric พร้อมกัน และเปิดแสดงแถวสรุปผลรวมท้ายตาราง (**`Show summary row`**) ได้
2. **แผนภูมิอนุกรมเวลา (`Add a chart` → `Time Series` — สไลด์หน้า 126–138)**:
   - **กฎเหล็กของฟิลด์วันเดือนปีใน Time Series (สไลด์หน้า 126 — ออกสอบเน้นมาก!)**:
     - ถ้าเก็บข้อมูลเป็น **ปีและเดือน** ต้องใช้รูปแบบ **`YYYY-MM`** เช่น **`2026-01`**
     - ถ้าเก็บข้อมูลเป็น **ปี เดือน และวัน** ต้องใช้รูปแบบ **`YYYY-MM-DD`** เช่น **`2026-01-01`**
     - **ข้อห้ามเด็ดขาด**: **ห้ามใช้ชื่อเดือนเป็นภาษาไทย** หรือ **ใส่เฉพาะเดือนอย่างเดียวโดยไม่มีปี** และควรใช้ปี **ค.ศ.** ไม่ใช่ พ.ศ.
   - **การตั้งค่า Time Series ขั้นสูง**:
     - หากต้องการแยกเส้นกราฟเปรียบเทียบรายปี (เช่น เปรียบเทียบแนวโน้มการใช้ยากลุ่ม NSAIDs ซ้ำซ้อนในแต่ละเดือนของปี 2022–2025 จากไฟล์ `ข้อมูลRDU_NSAIDs_ซ้ำซ้อน_2565_2568.xlsx`):
       - กำหนด `Dimension` (แกน X) เป็นฟิลด์ `ปี-เดือน` โดยคลิกที่รูปดินสอเพื่อปรับ `Data Type` / `Display Format` ให้เป็น **`Month`** หรือ **`Month Abbreviation`** (ชื่อย่อเดือน Jan, Feb, Mar...)
       - กำหนด `Breakdown Dimension` เป็นฟิลด์ `ปี-เดือน` ที่ปรับ `Data Type` เป็น **`Year`** (เพื่อให้แยกสีเส้นตามปี)
     - **`Default date range filter`**: ใช้กำหนดให้กราฟแสดงเฉพาะช่วงเวลาหรือเฉพาะปีที่ต้องการ (`Custom`) หรือตามค่าเริ่มต้น (`Auto`)
     - **`Comparison date range`**: ใช้เปรียบเทียบข้อมูลกับช่วงเวลาก่อนหน้า (เช่น เปรียบเทียบปี 2024 กับปี 2023)
       - **ข้อควรระวัง (สไลด์หน้า 136)**: **ถ้ามีการกำหนด `Breakdown Dimension` เอาไว้ก่อนหน้านี้ เส้นกราฟเปรียบเทียบ (`Comparison date range`) อีกเส้นอาจไม่ปรากฏ!**
     - ในแท็บ **`Style`** ของ Time Series: สามารถเพิ่ม **เส้นแนวโน้ม (`Trendline` เช่น แบบ `Linear`)** และ **เส้นอ้างอิงเกณฑ์เป้าหมาย (`Reference Line` เช่น เป้าหมายการใช้ยา NSAIDs ซ้ำซ้อนไม่เกิน 5%)** ได้

## ส่วนที่ 6: ตัวควบคุมการโต้ตอบ (Controls) ทั้ง 6 รูปแบบ (CLO3, CLO4) ⭐⭐⭐

การเพิ่มปุ่มหรือกล่องควบคุมเพื่อให้ผู้ชมรายงาน (Viewer) กรองและปรับมุมมองข้อมูลได้เอง ทำได้ผ่านเมนู **`Add a control`**:

| ชนิดของ Control | หน้าที่และการตั้งค่าสำคัญ | ตัวอย่างการใช้งานในสไลด์ |
| :--- | :--- | :--- |
| **1. `Drop-down list`** *(สไลด์หน้า 97–101)* | แสดงรายการตัวเลือกแบบเมนูพับลงให้คลิกเลือกกรองข้อมูล โดยที่ช่อง `Metric` สามารถใส่ค่าตัวเลข (เช่น `คะแนนประเมิน` แบบ `AVG` ทศนิยม 2 ตำแหน่ง) เพื่อแสดงกำกับด้านหลังตัวเลือกใน Drop-down ได้ | เลือกกรองตาม `หน่วยงาน` หรือ `ตำแหน่ง` |
| **2. `Input box`** *(สไลด์หน้า 102–104)* | กล่องให้ผู้ใช้งาน **พิมพ์คำค้นหา (Keyword)** เพื่อกรองข้อมูลในฟิลด์ที่กำหนด (`Control field`) โดยต้องกำหนด **`Search Type`** | ค้นหาฟิลด์ `เพศ` (`ชาย`, `หญิง`) ด้วย `Equals`, `Contains`, หรือ `Starts with` |
| **3. `Slider`** *(สไลด์หน้า 105–108)* | แถบเลื่อนสำหรับ **กำหนดช่วงของค่าตัวเลข (Numeric Range)** ที่ต้องการกรอง | เลือก `Control field` เป็นฟิลด์ตัวเลข เช่น **`คะแนนประเมิน (100)`** หรือ `อายุ` เพื่อเลื่อนดูเฉพาะช่วงคะแนนที่ต้องการ |
| **4. `Dimension control`** *(สไลด์หน้า 109–113)* | ช่วยให้ผู้ชมรายงาน (Viewer) **สลับตัวแปรหลัก (Dimension) ของแผนภูมิหรือตารางบนหน้าแดชบอร์ดได้ด้วยตัวเองแบบไดนามิก** ช่วยประหยัดพื้นที่ (สร้างชาร์ตเดียวแต่ดูได้หลายมิติ) และเพิ่มอิสระให้ผู้บริหารหา Insight เชิงลึก | ใส่ `Control field` ไว้ 3 มิติ คือ **`หน่วยงาน`**, **`ระดับการศึกษา`**, และ **`เพศ`** เพื่อให้ผู้ชมกดสลับแกนของกราฟได้ทันที |
| **5. `Date range control`** *(สไลด์หน้า 139–145)* | ปฏิทินให้ผู้ชมรายงานคลิกเลือกเปลี่ยน **ช่วงเวลา (วันเริ่มต้น–วันสิ้นสุด)** ของข้อมูลทั้งหมดบนหน้าจอได้เอง ช่วยเพิ่มความยืดหยุ่นและลดความซ้ำซ้อนไม่ต้องสร้างกราฟแยกปี | ตั้งค่า `Default date range filter` เป็น `Auto date range` เพื่อควบคุมกราฟ Time Series |
| **6. `Button`** *(สไลด์หน้า 176–182)* | ปุ่มกดสำหรับเชื่อมโยงไปยังหน้ารายงานอื่นภายใน Dashboard หรือเปิดลิงก์ URL ภายนอก | ตั้งค่าที่ `Button properties` → `Setup` → **`Insert link`** เพื่อทำปุ่มเมนูนำทางไปยังหน้าต่างๆ และปุ่มกลับหน้าแรก |

> [!TIP]
> **ความแตกต่างของ `Search Type` ทั้ง 3 รูปแบบใน `Input box` เมื่อต้องการค้นหาคำว่า `"หญิง"` จากฟิลด์ `เพศ` (สไลด์หน้า 103–104 — ออกสอบบ่อย!)**:
> 1. **`Equals` (ตรงกันทุกตัวอักษร)**: ต้องพิมพ์คำว่า **`หญิง`** เต็มคำจึงจะพบข้อมูล (พิมพ์แค่ `ห` หรือ `ญ` จะไม่พบ)
> 2. **`Contains` (มีคำนี้อยู่ส่วนใดก็ได้)**: พิมพ์แค่ตัวอักษรส่วนใดส่วนหนึ่งที่มีอยู่ในคำ เช่น พิมพ์ **`ญ`** (หรือ `ห`, `ญิ`) ก็พบข้อมูลคำว่า `หญิง`
> 3. **`Starts with` (ขึ้นต้นด้วยคำนี้)**: ต้องพิมพ์ตัวอักษรตัวแรกของคำ เช่น พิมพ์ **`ห`** จึงจะพบคำว่า `หญิง` (หากพิมพ์ `ญ` จะไม่พบเพราะไม่ได้ขึ้นต้นด้วย `ญ`)

## ส่วนที่ 7: การจัดการฐานข้อมูล การรวมตาราง (Blend Data) และ Join Operators 5 รูปแบบ (CLO3, CLO4) ⭐⭐⭐

### 7.1 การอัปเดตโครงสร้างเมื่อเพิ่มคอลัมน์ใหม่ใน Google Sheet (สไลด์หน้า 114–121 — ออกสอบเน้น!) ⭐⭐⭐
เมื่อมีการเพิ่มคอลัมน์ใหม่ลงใน Google Sheet ที่เชื่อมต่อกับ Dashboard อยู่แล้ว (เช่น เพิ่มคอลัมน์ **`ความพร้อมขึ้นเวรนอกเวลา`**) ชื่อฟิลด์ใหม่จะยังไม่ปรากฏใน Data Studio ทันที ต้องทำตาม **6 ขั้นตอนของการ Reconnect** ดังนี้:
1. เพิ่มคอลัมน์ข้อมูลใหม่ในไฟล์ Google Sheet
2. ที่หน้าจอ Data Studio คลิกเมนูด้านบน **`Resource`** → เลือก **`Manage added data sources`**
3. คลิกปุ่ม **`Edit`** ที่ชื่อ Google Sheet ที่เป็นฐานข้อมูล
4. คลิก **`Edit Connection`** (มุมซ้ายบน)
5. คลิกปุ่ม **`Reconnect`** (มุมขวาบน)
6. จะปรากฏหน้าต่าง **`Apply Connection Changes?`** แสดงรายชื่อฟิลด์ใหม่ (`New fields`) → คลิก **`Apply`**

*(ส่วนกรณีต้องการเพิ่มตารางข้อมูลจากไฟล์ Google Sheet อื่นเข้ามาใหม่ ให้คลิกปุ่ม **`Add data`** บน Toolbar → เลือก `Google Sheets` → เลือก Spreadsheet และ Worksheet เช่น `รายชื่อยาในคลัง_MockData` และ `การเบิกจ่ายยา_MockData` → คลิก `Add` ตามสไลด์หน้า 122–125)*

### 7.2 การรวมตารางข้อมูล (`Blend Data`) (สไลด์หน้า 146–166 — ออกสอบเน้นมาก!) ⭐⭐⭐
- **ความหมายของ `Blend data`**: ฟีเจอร์ที่ช่วยให้นำข้อมูลจากหลายแหล่ง (Data Sources) หรือหลายตารางมาเชื่อมโยงและรวมเข้าด้วยกัน เพื่อนำมาแสดงผลในกราฟ แผนภูมิ หรือตารางเดียวกันได้
- **ขีดจำกัดสำคัญ**: รองรับการรวมตารางได้ **สูงสุด 5 ตาราง**
- **ขั้นตอนการทำ Blend Data**:
  1. คลิกเมนู **`Resource`** → เลือก **`Manage blends`** → คลิก **`Add a blend`**
  2. เลือกตารางแรก แล้วคลิก **`Join another table`** เพื่อเพิ่มตารางที่ 2 และ 3
  3. เลือก Dimension และ Metric ที่ต้องการนำมาใช้จากแต่ละตาราง
  4. คลิก **`Configure join`** เพื่อเลือกรูปแบบการเชื่อมต่อ (**Join operator**) และกำหนดฟิลด์ที่เป็นคีย์เชื่อมโยง (**Join conditions**)

### 7.3 เปรียบเทียบรูปแบบการเชื่อมต่อตาราง (Join Operators ทั้ง 5 รูปแบบ — สไลด์หน้า 155–160) ⭐⭐⭐
จากตัวอย่างในสไลด์หน้า 156–160 กำหนดให้:
- **ตารางซ้าย (`รายชื่อลูกค้า` — 3 แถว)**: ลูกค้า **`A`** (กรุงเทพฯ), **`B`** (นครปฐม), **`C`** (ราชบุรี)
- **ตารางขวา (`ประวัติการซื้อ` — 3 แถว)**: ลูกค้า **`B`** (Paracetamol), **`C`** (Ibuprofen), **`D`** (ORS)

| รูปแบบ Join Operator | หลักการทำงาน | ผลลัพธ์จากตัวอย่าง (ตารางซ้าย `A, B, C` เชื่อมกับ ตารางขวา `B, C, D`) |
| :--- | :--- | :--- |
| **1. `Inner Join`** *(เฉพาะคู่ที่ตรงกัน)* | หาจุดที่เหมือนกัน (**Intersection**) ดึงมาเฉพาะแถวที่มีรหัส/ชื่อตรงกัน **ทั้งสองตารางเท่านั้น** | ได้เฉพาะลูกค้า **`B` และ `C`** เท่านั้น (รวม **2 แถว**; ตัด `A` และ `D` ทิ้ง) |
| **2. `Left Outer Join`** *(ยึดตารางซ้ายเป็นหลัก)* | ดึงข้อมูลจาก **ตารางซ้ายทั้งหมด** มาไว้ก่อน แล้วดึงข้อมูลที่ตรงกันจากตารางขวามาใส่ หากแถวใดในตารางซ้ายไม่มีคู่ในตารางขวา จะแสดงค่าว่าง (**`NULL`**) | ได้ลูกค้า **`A`, `B` และ `C`** ครบตามตารางซ้าย (รวม **3 แถว**; โดย **`A` จะมีช่องประวัติการซื้อเป็น `NULL`** ส่วน `D` ถูกตัดออก) |
| **3. `Right Outer Join`** *(ยึดตารางขวาเป็นหลัก)* | ดึงข้อมูลจาก **ตารางขวาทั้งหมด** มาไว้ก่อน แล้วดึงข้อมูลที่ตรงกันจากตารางซ้ายมาใส่ หากแถวใดในตารางขวาไม่มีคู่ในตารางซ้าย จะแสดงค่าว่าง (**`NULL`**) | ได้ลูกค้า **`B`, `C` และ `D`** ครบตามตารางขวา (รวม **3 แถว**; โดย **`D` จะมีช่องที่อยู่เป็น `NULL`** ส่วน `A` ถูกตัดออก) |
| **4. `Full Outer Join`** *(รวมทั้งหมด)* | นำข้อมูลของ **ทั้งสองตารางมารวมกันทั้งหมด** คู่ไหนตรงกันก็จับคู่ให้ อันไหนไม่มีคู่ก็ปล่อยเป็นค่าว่าง (**`NULL`**) | ได้ลูกค้า **`A`, `B`, `C` และ `D` ครบทุกคน** (รวม **4 แถว**; โดย `A` มีประวัติการซื้อเป็น `NULL` และ `D` มีที่อยู่เป็น `NULL`) |
| **5. `Cross Join`** *(จับคู่แบบทวีคูณ)* | นำตารางซ้ายทุกบรรทัด ไปจับคู่สลับกับตารางขวาทุกบรรทัด (**แทบไม่ถูกนำมาใช้งานจริง**) | ได้จำนวนแถวเท่ากับ **`3 × 3 = 9 บรรทัด`** |

### 7.4 กรณีศึกษาการเชื่อม 3 ตารางในปฏิบัติการเภสัชกรรม (สไลด์หน้า 152–163 — ออกสอบวิเคราะห์!) ⭐⭐⭐
เมื่อต้องการรวม 3 ตารางเข้าด้วยกันตามลำดับจากซ้ายไปขวา ได้แก่:
`[ตารางที่ 1: ข้อมูลบุคลากรฝ่ายเภสัชกรรม]` ➔ `[ตารางที่ 2: การเบิกจ่ายยา]` ➔ `[ตารางที่ 3: รายชื่อยาในคลัง]`
1. **คีย์หลัก (Dimension) ที่จำเป็นต้องใช้เชื่อมโยง 3 ตาราง (สไลด์หน้า 153)**:
   - เชื่อมตารางที่ 1 (`ข้อมูลบุคลากร`) กับ ตารางที่ 2 (`การเบิกจ่ายยา`) ด้วยฟิลด์ **`รหัสพนักงาน`** (เช่น `PH001`)
   - เชื่อมตารางที่ 2 (`การเบิกจ่ายยา`) กับ ตารางที่ 3 (`รายชื่อยาในคลัง`) ด้วยฟิลด์ **`รหัสยา`** (เช่น `D001`)
2. **การเลือก Join Operator ที่ปลอดภัยที่สุดเพื่อไม่ให้ข้อมูลการเบิกจ่ายยาตกหล่น (สไลด์หน้า 161–162)**:
   - **คู่ที่ 1 (`ข้อมูลบุคลากร` [ซ้าย] ⋈ `การเบิกจ่ายยา` [ขวา])**: เลือก **`Right Outer Join`** (ยึดตาราง `การเบิกจ่ายยา` ด้านขวาเป็นหลัก)
     - *เหตุผล*: **ปลอดภัยกว่า `Inner Join`** เพราะในกรณีที่มีการพิมพ์ **`รหัสพนักงาน` ผิด** ในตารางเบิกจ่ายยา รายการเบิกจ่ายยาที่พิมพ์รหัสผิดนั้นก็จะ **ยังคงแสดงให้เห็น (ไม่โดนตัดทิ้งไป)**
   - **คู่ที่ 2 (`การเบิกจ่ายยา` [ซ้าย] ⋈ `รายชื่อยาในคลัง` [ขวา])**: เลือก **`Left Outer Join`** (ยึดตาราง `การเบิกจ่ายยา` ด้านซ้ายเป็นหลัก)
     - *เหตุผล*: **ปลอดภัยกว่า `Inner Join`** เพราะในกรณีที่มีการพิมพ์ **`รหัสยา` ผิด** ในตารางเบิกจ่ายยา รายการเบิกจ่ายยาที่ผิดนั้นก็จะ **ยังคงแสดงให้เห็น ไม่โดนตัดทิ้งไป**

## ส่วนที่ 8: การจัดการหน้า การฝัง URL การซ่อนเมนูนำทาง และการเผยแพร่ Dashboard (CLO1, CLO3, CLO4) ⭐⭐⭐

### 8.1 การจัดการหน้ารายงาน (`Page`) และการซ่อนแถบเมนูนำทาง (`Navigation`) (สไลด์หน้า 80–85, 172–185) ⭐⭐
- **เมนู `Page` ด้านบน**:
  - `New page`: เพิ่มหน้าใหม่
  - `Duplicate page`: ทำซ้ำหน้าเดิม
  - `Delete page`: ลบหน้า
  - `Current page settings`: ปรับสีพื้นหลังและขนาดหน้ากระดาษเฉพาะหน้านั้น
  - `Manage pages`: จัดลำดับหน้า เปลี่ยนชื่อหน้า (สามารถคลิกเมาส์ซ้ายค้างแล้วย้ายหน้าที่สร้างใหม่ไปไว้ตำแหน่งบนสุดเพื่อให้เป็นหน้าแรกได้)
- **การซ่อนแถบเมนูนำทางด้านซ้าย (`Navigation` — สไลด์หน้า 183–185)**:
  - เมื่อเราสร้างหน้าแรกเป็นหน้าเมนูที่มีปุ่มกด (`Button`) เชื่อมต่อไปยังหน้าต่างๆ เองแล้ว แถบเมนูนำทางด้านซ้ายของระบบอาจกินพื้นที่หน้าจอและดูไม่สวยงาม
  - **วิธีซ่อน**: คลิกปุ่ม **`Theme and layout`** บน Toolbar → ไปที่แท็บ **`Layout`** → หัวข้อ **`Navigation type`** เปลี่ยนค่าเป็น **`Hidden`**

### 8.2 การฝังเนื้อหาจากภายนอกผ่าน `URL Embed` (สไลด์หน้า 167–171) ⭐⭐
- Data Studio สามารถนำเสนอเนื้อหาจากแหล่งภายนอกไว้ภายในหน้า Dashboard ได้โดยคลิกไอคอน **`URL Embed`** (`< >`) → ลากวางบนพื้นที่รายงาน → กรอกลิงก์ในช่อง **`External Content URL`**
- **ตัวอย่างสิ่งที่ฝังผ่าน `URL Embed` ได้**: Web application จาก **AppSheet**, วิดีโอจาก **YouTube**, แบบฟอร์ม **Google Form**, และหน้าเว็บไซต์ทั่วไป (**Website**)

### 8.3 ช่องทางการเผยแพร่ Dashboard ทั้ง 5 วิธี (สไลด์หน้า 186–198) ⭐⭐⭐
จากเมนู **`Share`** มุมขวาบนของหน้าจอ สามารถเผยแพร่ Dashboard ได้ 5 รูปแบบหลัก:
1. **เชิญเข้ามาดูหรือแก้ไขผ่านทาง Email (`Share` → `Invite people`)**:
   - ระบุอีเมลของผู้รับและกำหนดสิทธิ์เป็น **`Viewer`** (ดูได้อย่างเดียว) หรือ **`Editor`** (แก้ไขได้)
2. **การส่งรายงานผ่านทาง Email แบบตั้งเวลาส่งอัตโนมัติ (`Schedule email delivery`)**:
   - สามารถเลือกหน้าที่ต้องการส่ง และกำหนดวัน/เวลาที่จะให้ระบบส่งอีเมลรายงานอัตโนมัติได้
3. **การเผยแพร่ผ่านทาง Link (`Share` → `Get report link`)**:
   - เข้าไปที่ `View sharing settings` → กำหนดรูปแบบการเข้าถึงลิงก์เป็น **`Unlisted`** (เฉพาะคนที่มีลิงก์) หรือ **`Public`** (สาธารณะ) และเลือกสิทธิ์เป็น `Viewer` หรือ `Editor` → คัดลอกลิงก์ไปส่งต่อ
4. **การเผยแพร่ในรูปแบบการฝังที่เว็บไซต์อื่น (`Share` → `Embed report`)**:
   - นำ **`Embed Code` (HTML iframe)** หรือ Embed URL ไปวางในเว็บไซต์ส่วนตัวหรือเว็บไซต์ของหน่วยงานเพื่อแสดง Dashboard บนหน้าเว็บ
5. **การเผยแพร่ผ่านการดาวน์โหลดเป็นไฟล์ PDF (`Download report`)**:
   - สามารถเลือกดาวน์โหลดทุกหน้าหรือเฉพาะบางหน้า และ **สามารถตั้งรหัสผ่าน (`Password protect report`) ก่อนเปิดดูไฟล์ PDF ได้**
   - เมื่อเปิดไฟล์ PDF ผ่าน Chrome Browser แล้วคลิกเลือก `Document Outline` จะมีปุ่มลิงก์ให้กดเพื่อเปิดกลับไปยังหน้าเว็บไซต์ Dashboard ต้นฉบับได้

## ส่วนที่ 1: ภาพรวมของเว็บไซต์สร้างแอนิเมชัน 2 มิติ และการใช้งาน Animaker (CLO1) ⭐⭐⭐

### 1.1 ตัวอย่างเว็บไซต์ที่ให้บริการสร้างแอนิเมชัน (สไลด์หน้า 2–4) ⭐⭐⭐
เว็บไซต์ออนไลน์ยอดนิยมสำหรับสร้างวิดีโอแอนิเมชัน 2 มิติเพื่องานนำเสนอและสื่อสุขภาพที่ยกตัวอย่างในบทเรียนมี **6 เว็บไซต์** ได้แก่:
1. **Animaker** (`www.animaker.com`)
2. **Animatron**
3. **Biteable**
4. **Vyond**
5. **Powtoon**
6. **Renderforest**

### 1.2 จุดเด่นและระดับสมาชิกของ Animaker (สไลด์หน้า 5–9) ⭐⭐⭐
- **Animaker (`www.animaker.com`)**:
  - เป็นเว็บไซต์ที่ใช้สร้างวิดีโอแอนิเมชันสำหรับงานนำเสนอและสื่อการเรียนรู้
  - ใช้สร้างเรื่องราวเป็นการ์ตูนสั้น มีเครื่องมือสำเร็จรูปให้เลือกใช้มากมาย ใช้งานง่ายโดยไม่ต้องวาดเองทั้งหมด
- **เงื่อนไขการใช้งานและระดับสมาชิก (สไลด์หน้า 7–9)**:
  - **ต้องสมัครสมาชิกก่อนการใช้งาน**
  - สมาชิกแบ่งออกเป็นหลายระดับตามความต้องการ ได้แก่ **`Free`**, **`Basic`**, **`Starter`**, **`Pro`**, และ **`Enterprise`**:
    - **`Free`**: ได้ 300 AI Video credits/เดือน, 10 AI Assets/เดือน, พื้นที่อัปโหลดฟรี **2 GB**, และ **ดาวน์โหลดวิดีโอความยาวไม่เกิน 2 นาที** (แต่หากใช้วิธี **Share Link** จะสร้างวิดีโอความยาวได้ **ไม่จำกัด**!)
    - **`Basic`**: ความยาววิดีโอสูงสุด 5 นาที, 5 Premium Downloads/เดือน, 1,500 AI Video Credits/เดือน
    - **`Starter`**: ความยาววิดีโอสูงสุด 15 นาที, 10 Premium Downloads/เดือน, 90 วินาที Generative Video/เดือน, มี **Automatic BG removal tool**
    - **`Pro`**: ความยาววิดีโอสูงสุด 30 นาที, 30 Premium Downloads/เดือน
    - **`Enterprise`**: ความยาววิดีโอไม่จำกัด (`Unlimited video length`), มี `Global Edit` และ `Create and save templates`

## ส่วนที่ 2: การสร้างโปรเจกต์ใหม่ โครงสร้างหน้าจอ และการจัดการฉากหลัง (Background) (CLO1, CLO3, CLO4) ⭐⭐⭐

### 2.1 การสร้างโปรเจกต์ใหม่และสัดส่วนวิดีโอ (สไลด์หน้า 10–12) ⭐⭐⭐
1. คลิกปุ่ม **`Create`** → เลือก **`Create from Scratch`** (สร้างจากหน้าว่าง)
2. เลือกรูปแบบสไตล์ (`Cartoon` หรือ `Whiteboard`) และ **สัดส่วน VDO (Aspect Ratio)** ที่ต้องการ:
   - **`Horizontal Video` (`16:9`)**: วิดีโอแนวนอนมาตรฐาน (เช่น YouTube, งานนำเสนอ)
   - **`Square Video` (`1:1`)**: วิดีโอทรงจัตุรัส (เช่น โพสต์โซเชียลมีเดีย)
   - **`Vertical Video` (`9:16`)**: วิดีโอแนวตั้ง (เช่น Reels, Shorts, TikTok)
   - **`Custom Size`**: กำหนดความกว้าง (`Width`) และความสูง (`Height`) เอง
3. **องค์ประกอบหน้าจอหลักของ Animaker (สไลด์หน้า 12)**:
   - **แถบด้านบน**: ช่อง **ตั้งชื่อไฟล์** (ค่าเริ่มต้นคือ `Untitled Video`), ปุ่ม Preview (`Play`), ปุ่ม **`Share`** และปุ่ม **`Publish`** (มุมขวาบน)
   - **แถบเมนูเครื่องมือด้านซ้าย**: `Style`, `AI Tools`, `Templates`, `Character` (ตัวละคร), `Property` (สิ่งของ/รูปภาพประกอบ), `Elements`, `Text` (ข้อความ), `BG` (พื้นหลัง), `Media` / `Uploads`, `Music` (เพลง/เสียงประกอบ), `Effect` (เอฟเฟกต์), `More`
   - **พื้นที่ตรงกลาง (Workspace / Canvas)**: พื้นที่จัดวางฉากและตัวละคร
   - **แถบด้านขวา (`Scene Selection`)**: แสดงรายการฉาก (`Scene 1`, `Scene 2`, ...) และปุ่ม **`+ Add Scene`**
   - **แถบด้านล่าง (`Timeline`)**: แบ่งเป็น `Scene Timeline`, `Overall Timeline`, `Camera Timeline`, ปุ่ม `Play` ตรวจสอบงาน, และปุ่ม **`Layer`** สำหรับจัดลำดับการซ้อนทับ

### 2.2 การจัดการสีพื้นหลัง รูปฉากหลัง Effect และการสร้างพื้นหลังด้วย AI (สไลด์หน้า 13–29) ⭐⭐⭐
1. **การเปลี่ยนสีพื้นหลังและไล่โทนสี (Gradient) (สไลด์หน้า 13–17)**:
   - คลิกที่พื้นหลัง → คลิกปุ่ม **`Change Color`** → เลือกสีพื้นหลังเดี่ยวที่ต้องการ
   - หากต้องการ **พื้นหลังแบบไล่โทนสี (`Gradient`)**: สามารถเลือกใส่หลายสี และกำหนด **ทิศทางของการไล่สี** ได้โดยคลิกปุ่ม **`Direction`** (เช่น แนวตั้ง แนวนอน แนวทแยง หรือวงกลม)
2. **การใช้รูปภาพสำเร็จรูปเป็นฉากหลัง (`BG`) และการเปลี่ยนโทนสีของฉาก (สไลด์หน้า 18–22)**:
   - คลิกไอคอน **`BG`** ที่แถบเมนูด้านซ้าย → เลือกรูปฉากหลังที่ต้องการ (เช่น หมวด `Office`, `Healthcare`, `Retail`, `Hospitality`)
   - **ความสามารถพิเศษ**: รูปฉากหลังที่เลือกมา **สามารถเปลี่ยนโทนสีได้** โดยคลิกปุ่ม **`Change Color`** → เลือกโทนสีใหม่ แล้วบางส่วนของรูปฉากหลังจะปรับไปใช้โทนสีที่เลือกทันที
   - **การลบรูปภาพพื้นหลัง**: **คลิกขวาที่พื้นหลัง → เลือก `Delete`**
3. **การใส่และลบ `Effect` สำหรับพื้นหลัง (สไลด์หน้า 23–25)**:
   - คลิกไอคอน **`Effect`** (รูปดาววิบวับ) ที่แถบเมนูด้านซ้าย → เลือก Effect ที่ต้องการใส่ให้ฉาก
   - **การลบ Effect**: **คลิกขวาที่พื้นหลัง/Effect → เลือก `Delete`**
4. **การสร้างพื้นหลังด้วยปัญญาประดิษฐ์ (`Generate BG using AI` — สไลด์หน้า 26–29 — ออกสอบเน้น!)**:
   - ที่เมนู `BG` คลิกปุ่ม **`Generate BG using AI`**
   - **ขั้นตอนการตั้งค่า 3 ส่วนก่อนกดสร้าง**:
     1. ใส่ **`Prompt`** บรรยายลักษณะพื้นหลังที่ต้องการ
     2. เลือก **สี (`Color`)** ที่ต้องการคุมโทน
     3. เลือก **`Visual Style`** (รูปแบบศิลปะ เช่น `Vector Illustration`, `Galaxy` เป็นต้น)
   - จากนั้นคลิกปุ่ม **`Generate`**

## ส่วนที่ 3: การจัดการข้อความ (Text) และการสร้างตัวละครเคลื่อนไหว (Character & ActionPlus) (CLO3, CLO4) ⭐⭐⭐

### 3.1 การเพิ่มข้อความและใส่ Animation ให้ข้อความ (สไลด์หน้า 30–37) ⭐⭐⭐
1. คลิกไอคอน **`Text` (`T`)** ที่แถบด้านซ้าย → เลือกรูปแบบตัวอักษร (`Add a heading`, `Add a subheading`, `Add a little bit of body text` หรือดีไซน์สำเร็จรูป)
2. ปรับแต่งฟอนต์ ขนาด การจัดวาง ที่หน้าต่าง **`Edit Text`** และเปลี่ยนสีตัวอักษรที่ **`Change Color`**
3. **การใส่เอฟเฟกต์การแสดงผลของข้อความ (`Animation` — สไลด์หน้า 35–36)**:
   - คลิกที่ข้อความ → คลิกปุ่ม **`Animation`**
   - สามารถเลือกใส่ Animation ได้ทั้ง **2 จังหวะ** คือ:
     - **`Enter` (เอฟเฟกต์ตอนข้อความปรากฏเข้ามา)**
     - **`Exit` (เอฟเฟกต์ตอนข้อความหายออกไป)**
4. ตรวจสอบผลงานที่สร้างขึ้นได้โดยคลิกปุ่ม **`Play`** ด้านล่างของ VDO

### 3.2 การเพิ่มตัวละคร การสร้างตัวละครใหม่ และการตั้งค่าท่าทาง (`Action`, `Expression`, `ActionPlus`) (สไลด์หน้า 38–57) ⭐⭐⭐
1. **การเพิ่มและสร้างตัวละคร (`Character` — สไลด์หน้า 39–43)**:
   - คลิกไอคอน **`Character`** ที่แถบด้านซ้าย → คลิกเลือกตัวละครที่มีให้
   - หากต้องการ **สร้างตัวละครในรูปแบบของตนเองขึ้นมาใหม่**: คลิกปุ่ม **`Create your own character`** → ปรับแต่งทรงผม หน้าตา เสื้อผ้าตามต้องการ → คลิก **`Save`** ตัวละครจะถูกเก็บไว้ในหมวด `My Characters`
2. **การตั้งค่าท่าทางและอารมณ์พื้นฐาน (`Action` & `Expression` — สไลด์หน้า 44–45)**:
   - คลิกที่ตัวละคร → จะปรากฏหน้าต่าง **`Action`** ให้เลือกรูปแบบท่าทางการแสดงของตัวละคร (เช่น ยืน พูด โบกมือ นั่ง เดิน)
   - คลิกที่แท็บ **`Expression`** → เพื่อเลือกลักษณะ **การแสดงอารมณ์ทางสีหน้า** ของตัวละคร (เช่น ยิ้ม ดีใจ เศร้า โกรธ ตกใจ)
3. **การทำให้ตัวละครเคลื่อนที่พร้อมเปลี่ยนท่าทางต่อเนื่องด้วย `ActionPlus` (สไลด์หน้า 46–53 — ออกสอบเน้นมาก!)**:
   - **เมื่อใดต้องใช้ `ActionPlus`**: เมื่อต้องการให้ตัวละคร **มีการเคลื่อนที่เปลี่ยนตำแหน่ง พร้อมทั้งเปลี่ยนท่าทาง (Action) ไปด้วยอย่างต่อเนื่อง** (เช่น ท่าที่ 1 เดินเข้ามา → ท่าที่ 2 ยืนพูด → ท่าที่ 3 หันเตรียมเดิน → ท่าที่ 4 เดินออกไป)
   - **ขั้นตอนการใช้ `ActionPlus`**:
     1. คลิกที่ตัวละคร → คลิกปุ่ม **`ActionPlus`**
     2. ที่หน้าต่าง `ActionPlus` คลิกปุ่มเครื่องหมาย **`+`** เพื่อเพิ่มลำดับท่าทางใหม่
     3. เลือก `Action` ที่ต้องการเพิ่ม
     4. ลากตัวละครไปยังตำแหน่งปลายทางที่ต้องการบนฉาก → คลิกเครื่องหมายถูก (`✓`)
     5. เมื่อเพิ่ม Action ครบตามลำดับที่ต้องการแล้ว **ต้องคลิกปุ่ม `Apply`** เพื่อยืนยันการใช้งาน
   - **การแก้ไขหรือเปลี่ยน Action ในภายหลัง (สไลด์หน้า 51–52)**:
     - เมื่อต้องการแก้ไขลำดับท่าทาง → คลิก **`Edit Action`**
     - เมื่อต้องการเปลี่ยนท่าทางเดิมเป็นท่าใหม่ → คลิก **`Replace`** แล้วเลือก Action ใหม่ที่ต้องการ
4. **การปรับช่วงเวลาบน `Timeline` (สไลด์หน้า 54–57)**:
   - บน Timeline ด้านล่าง ผู้ใช้สามารถคลิกที่แถบของ **ตัวละคร, ข้อความ, หรือ Effect** เพื่อลากปรับ **ช่วงเวลาเริ่มต้นปรากฏ (Enter) และช่วงเวลาที่หายไป (Exit)** รวมถึงปรับระยะเวลาของแต่ละท่าทางใน `ActionPlus` (เช่น ท่าที่ 1 เดิน, ท่าที่ 2 ยืนพูด, ท่าที่ 3 หันเตรียมเดิน, ท่าที่ 4 เดิน) และเพิ่ม/ลดระยะเวลารวมของ Scene ได้

## ส่วนที่ 4: การจัดการเสียงพากย์ (Voice Over) และเพลงประกอบ (Music & Advanced Edit) (CLO3, CLO4) ⭐⭐⭐

### 4.1 การเพิ่มเสียงพากย์ตัวละคร (`Add a voice over`) ทั้ง 3 วิธี (สไลด์หน้า 58–63 — ออกสอบเน้น!) ⭐⭐⭐
เมื่อคลิกที่ตัวละครแล้วเลือก **`Add a voice over`** (รูปไมโครโฟน) สามารถใส่เสียงพากย์ให้ตัวละครขยับปากพูดตามเสียง (**Auto Lip-Sync**) ได้ **3 วิธี** คือ:
1. **`Record Voiceover`**: อัดเสียงพูดลงไปโดยตรงผ่านไมโครโฟน
2. **`Text to Speech`**: แปลงข้อความตัวอักษรเป็นเสียงพูดด้วย AI
   - **ความสามารถของ `Text to Speech` (สไลด์หน้า 60)**: สามารถเลือกเสียง **เพศชาย (`Male`) หรือเพศหญิง (`Female`)**, เลือก **ภาษา (`Language`)**, เลือก **น้ำเสียงคนพูดที่แตกต่างกัน (`Voice`)**, และ **สามารถระบุได้ว่าจะให้เน้นเสียงหนัก-เบาหรือหยุดเว้นจังหวะตรงคำไหน** → จากนั้นคลิก **`Add to Timeline`**
3. **`Upload Voiceover`**: อัปโหลดไฟล์เสียงที่มีอยู่แล้วในเครื่องคอมพิวเตอร์เข้ามาใช้งาน
- เสียงพูดที่ใส่เข้าไปบน Timeline สามารถลากจัดให้อยู่ในช่วงเวลาที่เหมาะสม และคลิก **`Edit`** เพื่อแก้ไขภายหลังได้

### 4.2 การแทรกเพลงประกอบ (`Music`) และการลดเสียงเพลงเมื่อมีเสียงพูด (`Advanced Edit`) (สไลด์หน้า 64–66 — ออกสอบเน้น!) ⭐⭐⭐
1. **การเพิ่มเพลงประกอบหรือ Sound effect**:
   - คลิกไอคอน **`Music`** ที่แถบด้านซ้าย → เลือกจากหมวด `Music` (เพลงบรรเลง), `Sound Effects` (เสียงเอฟเฟกต์สั้นๆ), หรือ `My Uploads` (ไฟล์เสียงที่อัปโหลดเอง)
   - ในสไลด์หน้า 93–94 แนะนำแหล่งดาวน์โหลดเพลงประกอบปลอดลิขสิทธิ์ (**Free background music / Royalty-free music**) 2 เว็บไซต์ ได้แก่:
     - `https://www.bensound.com/royalty-free-music/corporate-pop`
     - `https://www.fesliyanstudios.com/royalty-free-music`
2. **การแก้ปัญหาเสียงดนตรีดังกลบเสียงพูดด้วย `Advanced Edit` (Audio Ducking — สไลด์หน้า 65–66)**:
   - เมื่อเสียงดนตรีที่เพิ่มเข้าไปซ้อนทับกับช่วงที่มีเสียงพากย์ตัวละครพูด:
   - ให้คลิกที่ปุ่มจุดสามจุด (`...`) บนแถบเสียงเพลงใน Timeline → เลือก **`Advanced Edit`**
   - **วิธีปรับลดเสียง**: **ดึงเส้นตรงกราฟระดับเสียง (Volume envelope line) ในช่วงที่มีเสียงพูดลงมาด้านล่าง** เพื่อให้เสียงเพลงเบาลงเฉพาะช่วงที่ตัวละครกำลังพูด

---

## ส่วนที่ 5: การจัดลำดับซ้อนทับ (Layer), การจัดการ Scene, Smart Move, มุมกล้อง และ Transition (CLO3, CLO4) ⭐⭐⭐

### 5.1 การปรับลำดับการซ้อนทับ (`Layer`) และการเพิ่ม/ลบ `Scene` (สไลด์หน้า 67–70) ⭐⭐
- **การซ้อนทับกันของวัตถุ (`Layer`)**: คลิกปุ่ม **`Layer`** ที่มุมขวาล่างเหนือ Timeline เพื่อสลับลำดับวัตถุว่าชิ้นใดอยู่ด้านหน้าหรือด้านหลัง
- **การเพิ่มฉากใหม่ (`Add Scene`)**: คลิกปุ่ม **`+ Add Scene`** หรือปุ่มเครื่องหมาย `+` ที่แถบ Scenes ด้านขวา
- **การลบฉาก (`Delete Scene`)**: คลิกที่ไอคอนจุดสามจุดบน Scene ที่ต้องการลบ → เลือก **`Delete`**

### 5.2 การเพิ่มรูปภาพ (`Property`) และการกำหนด `Smart move` (สไลด์หน้า 71–75 — ออกสอบเน้น!) ⭐⭐⭐
- **การเพิ่มรูปภาพสิ่งของประกอบฉาก**: คลิกที่ไอคอน **`Property`** (รูปถ้วยกาแฟ) ที่แถบด้านซ้าย → เลือกรูปภาพสิ่งของหรืออุปกรณ์ที่ต้องการ
- **การกำหนด `Smart move` ให้กับรูปภาพหรือวัตถุ (สไลด์หน้า 73–75)**:
  - รูปภาพหรือวัตถุที่เพิ่มเข้ามาใน Scene สามารถกำหนดให้เคลื่อนที่ไปตามเส้นทางหรือรูปแบบที่ต้องการได้โดยคลิกที่วัตถุ → คลิกปุ่ม **`Smart move`** → เลือกรูปแบบการเคลื่อนที่ที่ต้องการ

### 5.3 การเปลี่ยนมุมกล้อง (`Camera Timeline`: Static vs Dynamic Camera) (สไลด์หน้า 76–80 — ออกสอบเน้น!) ⭐⭐⭐
ใน Animaker สามารถกำหนดมุมกล้องซูมเข้า-ออกหรือแพนกล้องได้ตามต้องการ โดยมีขั้นตอนดังนี้:
1. คลิกที่ไอคอน **`Camera Timeline`** (รูปกล้อง) บนแถบเหนือ Timeline
2. เลือกประเภทมุมกล้อง ซึ่งมี **2 รูปแบบ** คือ:
   - **`Static Camera`**: กล้องอยู่นิ่งกับที่
   - **`Dynamic Camera`**: กล้องมีการเคลื่อนไหว (เช่น ซูมเข้า-ออก หรือเลื่อนโฟกัสไปยังจุดที่กำหนด)
3. ปรับขนาดกรอบพื้นที่แสดงผลของกล้องบนหน้าจอ และปรับระยะเวลาการแสดงผลของกล้องที่ Timeline → เมื่อเสร็จแล้วคลิก **`Done`**

### 5.4 การเพิ่ม `Transition effect` ระหว่าง Scene (สไลด์หน้า 81–83) ⭐⭐
- ผู้ใช้งานสามารถเพิ่มเอฟเฟกต์การเปลี่ยนฉาก (**Transition effect**) ในช่วงรอยต่อระหว่าง Scene ได้โดยคลิกปุ่ม **`Add transition effect`** ที่ระหว่างฉากในหน้าต่าง **Scenes** ด้านขวา

## ส่วนที่ 6: การเชื่อมต่อแหล่งรูปภาพ การนำเข้าไฟล์ (Uploads) และการเผยแพร่ผลงาน (Publish vs Share) (CLO1, CLO4) ⭐⭐⭐

### 6.1 การเชื่อมต่อแหล่งรูปภาพเพิ่มเติม (`More`) และการนำเข้าไฟล์ (`Uploads`) (สไลด์หน้า 84–86) ⭐⭐⭐
- **การเชื่อมต่อแหล่งรูปภาพภายนอก**: ที่เมนู **`More` (`...`)** ด้านซ้ายล่างของ Animaker อนุญาตให้ผู้ใช้งานเชื่อมต่อแหล่งรูปภาพ/วิดีโอภายนอกเพิ่มเติม (เช่น Giphy, Pixabay, Unsplash) เพื่อนำมาใช้ในการสร้างแอนิเมชันได้
- **การนำเข้ารูปภาพและวิดีโอจากเครื่องของผู้ใช้ (`Uploads` — สไลด์หน้า 86)**:
  - นำเข้าผ่านเมนู **`Uploads`**
  - **จำกัดพื้นที่จัดเก็บฟรีสูงสุด `2 GB`** (สำหรับบัญชีฟรี)

### 6.2 เปรียบเทียบการเผยแพร่ผลงาน 2 วิธี: `Publish` VS `Share` (สไลด์หน้า 87–92 — ออกสอบเน้นมาก!) ⭐⭐⭐
ที่มุมขวาบนของหน้าเว็บไซต์ Animaker มีช่องทางการเผยแพร่ผลงาน **2 วิธีหลัก** ซึ่งมีข้อจำกัดเรื่องความยาววิดีโอสำหรับผู้ใช้ฟรี (**Free user**) แตกต่างกันอย่างชัดเจน:

| ประเด็นเปรียบเทียบ | วิธีที่ 1: `Publish` (การเผยแพร่ / ดาวน์โหลดไฟล์) | วิธีที่ 2: `Share` (การแชร์ลิงก์ / อีเมล) |
| :--- | :--- | :--- |
| **ขั้นตอนการทำงาน** | คลิกปุ่ม **`Publish`** มุมขวาบน → เลือกช่องทางการเผยแพร่ เช่น **`Download Video`** (ดาวน์โหลดเป็นไฟล์วิดีโอ), `Download GIF` หรือเผยแพร่ลงโซเชียลมีเดีย | คลิกปุ่ม **`Share`** มุมขวาบน → ระบุ **Email address** ของผู้รับแล้วคลิก `Send` หรือคลิก **`Copy`** เพื่อนำ **Link** ส่งให้ผู้อื่นเปิดดู |
| **ข้อจำกัดความยาววิดีโอสำหรับ `Free user`** | **สร้างและดาวน์โหลด VDO ที่มีความยาวได้ไม่เกิน `2 นาที` เท่านั้น!** | **สามารถสร้างและแชร์ VDO ที่มีความยาวได้ `ไม่จำกัด`!** |

## ส่วนที่ 1: ภาพรวมซอฟต์แวร์แอนิเมชัน 2 มิติ และโปรแกรม Synfig Studio (CLO1) ⭐⭐⭐

### 1.1 ตัวอย่างโปรแกรมสร้างแอนิเมชัน 2 มิติ (สไลด์หน้า 2–6) ⭐⭐
1. **Adobe Animate**: โปรแกรมยอดนิยมระดับมืออาชีพ มีค่าใช้จ่ายรายเดือน (ประมาณ 350.96 บาท/เดือน)
2. **MOHO (Moho 14)**: โปรแกรมแอนิเมชัน 2D ครบวงจรสำหรับสร้างการ์ตูนและ Rigging
3. **Harmony 22 (Toon Boom Harmony)**: โปรแกรมสร้างแอนิเมชันระดับสตูดิโอภาพยนตร์
4. **Mango Animation Maker**: โปรแกรมสร้างวิดีโอแอนิเมชันและกราฟิกเคลื่อนไหว
5. **Synfig Studio** (`https://www.synfig.org/` หรือดาวน์โหลดผ่าน `https://dappcdn.com/download/graphic-apps/synfig`)

### 1.2 คุณสมบัติและจุดเด่นของโปรแกรม Synfig Studio (สไลด์หน้า 7 — ออกสอบเน้น!) ⭐⭐⭐
- **เวอร์ชันล่าสุดที่อ้างอิงในบทเรียน**: **`1.4.5`**
- **ระบบปฏิบัติการที่รองรับ (OS Support)**: รองรับทั้ง **Linux, Mac OSX, และ Windows**
- **ประเภทใบอนุญาต (License)**: **Freeware / Open-source 2D Animation Software** (ใช้งานได้ฟรีโดยไม่มีค่าใช้จ่าย)
- **หลักการทำงาน**: ใช้สร้างภาพเคลื่อนไหว 2 มิติ ด้วยหลักการของ **Vector และ Bitmap** โดยการนำภาพนิ่งมาเรียงซ้อนกันเป็นภาพเคลื่อนไหว
- **จุดเด่นด้านฮาร์ดแวร์**: **ใช้ทรัพยากรเครื่องต่ำ (Low resource usage)**

### 1.3 ส่วนประกอบหน้าจอหลักของ Synfig Studio (สไลด์หน้า 8) ⭐⭐⭐
1. **แถบเครื่องมือด้านซ้าย (`Toolbox` & `จัดการสี`)**: รวมเครื่องมือวาดรูปทรง จัดการสีเส้นขอบ (**Outline Color**) สีพื้น (**Fill Color**) และขนาดหัวแปรง
2. **พื้นที่ตรงกลาง (`Working Area` / Canvas)**: พื้นที่ทำงานและแสดงผลแอนิเมชัน พร้อมไม้บรรทัด (Ruler) ปุ่ม Play และปุ่ม **Turn on animate editing mode**
3. **หน้าต่างมุมขวาบน (`Tool Options`)**: ตั้งค่าตัวเลือกเสริมของเครื่องมือที่กำลังใช้งาน
4. **หน้าต่างมุมซ้ายล่าง (`Parameter Panel`, `Keyframe Panel`)**: แสดงและปรับค่าคุณสมบัติของเลเยอร์ เช่น `Z Depth`, `Opacity` (ความโปร่งใส), `Blend Method`, `Color` (สี), `Radius` (รัศมี), `Feather` (ความฟุ้งของขอบ), `Origin`, `Transformation` (`Offset`, `Rotation`, `Scale`, `Skew`) และ `Active Layer Name`
5. **หน้าต่างตรงกลางด้านล่าง (`Time Track Panel`)**: แถบเส้นเวลาแสดงเฟรม (`0f, 24f, 48f, 96f, 120f...`) และจุด **Waypoint**
6. **หน้าต่างมุมขวาล่าง (`Layers Panel`)**: แสดงรายการเลเยอร์ (`Icon`, `Name`, `Z Depth`) และการจัดลำดับซ้อนทับ

## ส่วนที่ 2: เครื่องมือพื้นฐาน การจัดการ Layer ค่า Z Depth และจุดควบคุม 7 สี (CLO1, CLO3, CLO4) ⭐⭐⭐

### 2.1 การวาดวงกลม (`Circle Tool`) vs สี่เหลี่ยม (`Rectangle Tool`) และการรวมกลุ่ม (`Group Layer`) (สไลด์หน้า 9–15 — ออกสอบเน้น!) ⭐⭐⭐
- **การวาดวงกลม (`Circle Tool` — สไลด์หน้า 9–10)**:
  - คลิก `Circle Tool` → เลือกสีพื้น (`Fill Color`) → คลิกเมาส์ค้างแล้วลากบนพื้นที่ทำงาน
  - ปรับแต่งค่าสี ความโปร่งใส (`Opacity`) รัศมี (`Radius`) และ **ความฟุ้งของขอบ (`Feather`)** ได้ที่หน้าต่าง **`Parameter`**
  - วงกลมที่วาดขึ้นจะมี **จุดสีเขียวตรงจุดศูนย์กลาง** สามารถคลิกลากเพื่อย้ายตำแหน่งได้ทันที
- **ข้อควรระวังในการย้ายรูปสี่เหลี่ยม (`Rectangle Tool` — สไลด์หน้า 13–15 — ออกสอบเน้นมาก!)**:
  - สี่เหลี่ยมที่วาดขึ้นใหม่จะมีเฉพาะจุดสีเขียวที่มุมบนซ้าย (`Point 1`) และมุมล่างขวา (`Point 2`) สำหรับดึงขยายขนาด **แต่ยังไม่มีชุดจุดควบคุมสำหรับย้ายทั้งรูป**
  - **วิธีการเคลื่อนย้ายรูปสี่เหลี่ยม**: จึงแตกต่างจากการเคลื่อนย้ายวงกลม โดยต้อง **คลิกขวาที่ Layer ของสี่เหลี่ยม → เลือก `Group Layer`** (เปรียบเสมือนการนำสี่เหลี่ยมใส่เข้าไปในกล่องใสอีกที) → จากนั้นจะปรากฏชุดจุดควบคุม (Handle) ขึ้นมา ให้คลิกลากที่ **จุดสีเขียว** เพื่อเคลื่อนย้ายตำแหน่งของสี่เหลี่ยม

### 2.2 การจัดการลำดับเลเยอร์และค่า `Z Depth` (สไลด์หน้า 11–12 — ออกสอบเน้นมาก!) ⭐⭐⭐
- สามารถเปลี่ยนชื่อเลเยอร์ได้ที่หน้าต่าง `Layers` เพื่อให้จำง่าย
- **การสลับลำดับการซ้อนทับของเลเยอร์ทำได้ 2 วิธี**:
  1. คลิกขวาที่เลเยอร์ → เลือก **`Raise Layer`** (เลื่อนขึ้นด้านบน) หรือ **`Lower Layer`** (เลื่อนลงด้านล่าง)
  2. ดูหรือปรับจากค่า **`Z Depth`**:
     - **ค่า `Z Depth` น้อย จะแสดงอยู่ด้านบน (ด้านหน้า)**
     - **ค่า `Z Depth` มาก จะแสดงอยู่ด้านล่าง (ถูกทับอยู่ด้านหลัง)**
     - *ตัวอย่างในสไลด์หน้า 12*: เลเยอร์วงกลมสีม่วง (`Z Depth = 0.000000`) อยู่บนสุด ทับเลเยอร์สีน้ำเงิน (`Z Depth = 1.000000`) และเลเยอร์สีเหลือง (`Z Depth = 2.000000`) อยู่ล่างสุด

### 2.3 การนำเข้ารูปภาพและหน้าที่ของจุดควบคุมทั้ง 7 สี (Transformation Handles — สไลด์หน้า 16–20 — ออกสอบแน่นอน!) ⭐⭐⭐
- **การนำเข้ารูปภาพ**: ไปที่เมนู **`File` → `Import`** (คีย์ลัด `Ctrl + I`) หรือลากไฟล์รูปภาพมาวางบนพื้นที่ทำงานโดยตรง (เช่น นำเข้า `background.png` และ `boy.png` แล้วจัดให้เลเยอร์ `boy` อยู่เหนือ `background`)
- **หน้าที่ของจุดควบคุม (Handles) แต่ละสีเมื่อเลือก Group Layer หรือรูปภาพ (สไลด์หน้า 18)**:

| สีและตำแหน่งของจุด (Handle) | หน้าที่การทำงาน (ตามสไลด์หน้า 18) |
| :--- | :--- |
| **1. จุดสีเขียว (`Green dot` — ตรงกลาง)** | **เคลื่อนย้ายตำแหน่ง (`Move / Offset`)** ของวัตถุ |
| **2. จุดสีน้ำเงิน (`Blue dot`)** | **หมุนวัตถุ (`Rotate`)** รอบจุดหมุน |
| **3. จุดสีส้ม (`Orange dot` — มุมขวาบน)** | **ปรับขนาดแบบยังคงสัดส่วนเดิม (`Scale proportionally`)** ทั้งแนวตั้งและแนวนอนพร้อมกัน |
| **4. จุดสีเหลืองด้านบน (`Top Yellow dot`)** | **ปรับขนาดตามแนวแกน X** *(ตามคำบรรยายในสไลด์หน้า 18)* |
| **5. จุดสีเหลืองด้านขวา (`Right Yellow dot`)** | **ปรับขนาดตามแนวแกน Y** *(ตามคำบรรยายในสไลด์หน้า 18)* |
| **6. จุดสีแดง (`Red dot`)** | **ปรับเอียง (`Skew`)** บิดรูปทรงให้ลาดเอียง |
| **7. จุดสีเทา (`Grey dot` — ด้านล่าง)** | **ลากเพื่อเปลี่ยนจุดหมุน (`Pivot / Origin point`)** โดยที่ตัววัตถุไม่ขยับเปลี่ยนตำแหน่ง (สำคัญมากในการทำจุดหมุนข้อต่อแขน ขา คอ ลำตัว!) |

## ส่วนที่ 3: การสร้างภาพเคลื่อนไหวพื้นฐาน Waypoint และรูปแบบการเคลื่อนที่ 5 รูปแบบ (Interpolation) (CLO1, CLO3, CLO4) ⭐⭐⭐

### 3.1 ขั้นตอนการสร้างภาพเคลื่อนไหวและการดูตัวอย่าง (Preview) (สไลด์หน้า 21–27) ⭐⭐⭐
1. วางวัตถุ (`Boy`) ในตำแหน่งเริ่มต้นที่เฟรม `0f`
2. คลิกปุ่ม **`Turn on animate editing mode`** (ไอคอนรูปคนสีเขียวที่มุมขวาล่างของพื้นที่ทำงาน จะเปลี่ยนเป็น **ไอคอนรูปคนวิ่งสีแดง** และมีกรอบสีแดงล้อมรอบพื้นที่ทำงาน)
3. ที่หน้าต่าง `Time Track` คลิกเลือกเฟรมปลายทางที่ต้องการ:
   - **หลักการความเร็ว (สไลด์หน้า 23)**: **ยิ่งจำนวนเฟรมมาก = การเคลื่อนที่ยิ่งช้าลง / ยิ่งจำนวนเฟรมน้อย = การเคลื่อนที่ยิ่งเร็วขึ้น**
4. ลากวัตถุไปยังตำแหน่งปลายทาง → จะเกิดสัญลักษณ์ **`Waypoint`** บนหน้าต่าง Time Track
5. **การตรวจสอบการเคลื่อนไหว (Preview) ทำได้ 2 วิธี (สไลด์หน้า 25–26)**:
   - **วิธีที่ 1**: คลิกปุ่ม **`Play`** ที่แถบด้านล่างของ Working Area
   - **วิธีที่ 2**: คลิกไอคอน **`Preview`** (รูปหน้าจอแว่นขยาย) ที่แถบด้านบนของ Working Area (สามารถตั้งค่า `Quality`, `FPS` เช่น 24 เฟรมต่อวินาที, `Begin time` และ `End time` ได้)
6. **การแก้ไข Waypoint (สไลด์หน้า 27)**:
   - คลิกขวาที่ Waypoint เพื่อสั่งแก้ไข (`Edit`), ลบ (`Remove`), หรือทำซ้ำ (**`Duplicate`** — เมื่อเลือกเฟรมใหม่แล้วคลิกขวาที่ Waypoint เดิมเพื่อกด `Duplicate` วัตถุจะเคลื่อนที่กลับมายังตำแหน่งของ Waypoint ที่ถูกทำซ้ำนั้น)

### 3.2 รูปแบบการเคลื่อนที่ (Interpolation / Waypoint Types) ทั้ง 5 รูปแบบ (สไลด์หน้า 28–29 — ออกสอบแน่นอน!) ⭐⭐⭐

| รูปแบบการเคลื่อนที่ (สีสัญลักษณ์) | ลักษณะการเคลื่อนที่ | ข้อดี / ข้อเสีย / งานที่เหมาะสม |
| :--- | :--- | :--- |
| **1. `Clamped` (สีส้ม)** | เคลื่อนที่อย่างนุ่มนวลและ **หยุดตรงเป้าหมายพอดี** | **ไม่เกิดอาการเด้งเลยจุด (No Overshoot)** เป็นค่าที่ปลอดภัยและ **แนะนำให้ใช้เป็นหลัก** |
| **2. `TCB` (สีเขียว)** | เคลื่อนที่อย่างลื่นไหลและสมูทมาก | **ข้อเสียสำคัญ**: เกิดอาการ **"Overshoot"** (วัตถุเคลื่อนที่เลยตำแหน่งเป้าหมายไปแล้วเด้งดึงกลับมา) |
| **3. `Constant` (สีแดง)** | **ไม่มีการเคลื่อนที่ในระหว่างทาง** วัตถุจะอยู่นิ่งที่ตำแหน่งเดิม แล้ว **สลับเปลี่ยนทันทีเมื่อถึงเฟรมเป้าหมาย (จุด B)** | เหมาะกับงานที่ต้องการสลับภาพทันที เช่น **การกะพริบตา** หรือ **การสลับรูปปากเวลาตัวละครพูด (Lip-Sync)** |
| **4. `Ease In/Out` (สีน้ำเงิน)** | เคลื่อนที่แบบมีแรงเฉื่อยตามธรรมชาติ คือ **ออกตัวช้า → เร่งความเร็วตรงกลาง → ค่อยๆ เบรกชะลอความเร็วก่อนหยุด** | ให้ความรู้สึกลื่นไหลเป็นธรรมชาติสำหรับวัตถุจริง |
| **5. `Linear` (สีเหลือง)** | เคลื่อนที่ด้วย **ความเร็วคงที่เท่ากันตั้งแต่ต้นจนจบ** | ไม่มีจังหวะเร่งหรือชะลอ ทำให้การเคลื่อนไหวดู **แข็งทื่อคล้ายหุ่นยนต์** |

### 3.3 การบันทึกและแปลงไฟล์ส่งออก (Render Settings) ทั้ง 3 รูปแบบ (สไลด์หน้า 30–33 — ออกสอบเน้น!) ⭐⭐⭐
- **นามสกุลไฟล์โปรเจกต์ต้นฉบับของ Synfig**: **`.sifz`** (ใช้เปิดแก้ไขงานต่อในโปรแกรม Synfig)
- **การแปลงไฟล์เพื่อนำไปใช้งานจริง (`Render`) แบ่งออกเป็น 3 รูปแบบหลัก**:

| รูปแบบไฟล์ปลายทาง | การตั้งค่า `Filename` | การตั้งค่า `Target` ในหน้าต่าง Render Settings | หมายเหตุสำคัญ |
| :--- | :--- | :--- | :--- |
| **1. ไฟล์วิดีโอ (`.avi`)** | ตั้งนามสกุลต่อท้ายเป็น **`.avi`** | กำหนด `Target` เป็น **`Auto`** → คลิก `Render` | ได้ไฟล์ VDO ภาพเคลื่อนไหวพร้อมเสียง |
| **2. ภาพเคลื่อนไหว (`.gif`)** | ตั้งนามสกุลต่อท้ายเป็น **`.gif`** | กำหนด `Target` เป็น **`gif`** → คลิก `Render` | ได้ไฟล์ภาพเคลื่อนไหวแบบ GIF |
| **3. ภาพนิ่ง (`.png`)** | ตั้งนามสกุลต่อท้ายเป็น **`.png`** | กำหนด `Target` เป็น **`png`** → คลิก `Render` | หากต้องการแปลงเฉพาะเฟรมที่กำลังเลือกอยู่เพียงภาพเดียว ต้องติ๊กถูกที่ช่อง **`Render current frame only`** |

## ส่วนที่ 4: การประกอบตัวการ์ตูน การกลับด้านภาพ และความแตกต่างระหว่าง Waypoint VS Keyframe (CLO3, CLO4) ⭐⭐⭐

### 4.1 การประกอบชิ้นส่วนร่างกายและการกำหนดจุดหมุน (`handMove` — สไลด์หน้า 34–46) ⭐⭐⭐
1. เตรียมไฟล์ภาพแยกชิ้นส่วน (`head.png`, `body.png`, `hand.png`, `leg.png`) → นำเข้าด้วย `File -> Import`
2. เลือกทุกเลเยอร์ → คลิกขวา → **`Group Layer`** → ย่อขนาดรวมทั้งกลุ่มด้วย **จุดสีส้ม**
3. การทำแขนหรือขาอีกข้าง: คลิกขวาที่เลเยอร์แขน/ขา → เลือก **`Duplicate Layer`**
4. **เทคนิคการกลับด้านภาพซ้าย-ขวา (Flip Horizontally — สไลด์หน้า 42 — ออกสอบเน้น!)**:
   - คลิกเลือกเลเยอร์ที่ต้องการกลับด้าน → ไปที่หน้าต่าง **`Parameter`** → ขยายหัวข้อ **`Transformation`** → ที่บรรทัด **`Scale`** ให้ **เติมเครื่องหมายลบ (`-`) ด้านหน้าตัวเลขตัวแรก (แกน X)** เช่น จาก `(60.000000px, 60.000000px)` เป็น **`(-60.000000px, 60.000000px)`** → แล้ว **กดปุ่ม `Enter` 2 ครั้ง**
5. **การย้ายจุดหมุน (`Grey dot`) ของแต่ละชิ้นส่วน (สไลด์หน้า 40–46)**:
   - ลาก **จุดสีเทา** ของแขน (`hand`) ไปไว้ที่ **หัวไหล่**, ของศีรษะ (`head`) ไปไว้ที่ **คอ**, ของขา (`leg`) ไปไว้ที่ **สะโพก**
   - เลือกเลเยอร์ `head`, `body` และ `hand` ทั้งสองข้างมารวมกลุ่ม (`Group Layer`) อีกชั้นหนึ่ง แล้วลากจุดสีเทาของกลุ่มส่วนบนนี้มาไว้ที่ **เอว/สะโพก** เพื่อให้ตัวละครก้มหรือเอียงลำตัวช่วงบนไปพร้อมกันได้อย่างเป็นธรรมชาติ

### 4.2 เปรียบเทียบความแตกต่างระหว่าง `Waypoint` VS `Keyframe` (สไลด์หน้า 47–60 — ออกสอบแน่นอน!) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | การใช้เฉพาะ `Waypoint` (สไลด์หน้า 48–54) | การใช้ `Keyframe` (สไลด์หน้า 55–60) |
| :--- | :--- | :--- |
| **หลักการจดจำค่า** | **จดจำค่าเฉพาะในจุดเวลาของเลเยอร์/พารามิเตอร์ที่มีการขยับเท่านั้น** (ไม่จำสถานะของเลเยอร์อื่นที่ไม่ได้ขยับในเฟรมนั้น) | **จดจำค่าในแต่ละจุดของเวลา และจดจำสถานะของทุกเลเยอร์ทั้งหมดไว้ด้วย** (แสดงเป็นเส้นประแนวตั้งสีน้ำตาลล็อกทุกเลเยอร์) |
| **ปัญหาที่พบเมื่อขยับคนละเลเยอร์ต่างเวลากัน** | เช่น เฟรมที่ 10 ขยับแขนซ้าย (เกิด Waypoint ที่ 0f และ 10f ของแขนซ้าย) พอไปเฟรมที่ 20 ขยับแขนขวา (เกิด Waypoint ที่ 0f และ 20f ของแขนขวา) **จะทำให้แขนขวาแอบขยับตั้งแต่เฟรม 0 ถึง 10 ไปด้วยทั้งที่ไม่ได้ต้องการ!** | เมื่อเพิ่ม Keyframe ที่เฟรม 10 (ขยับแขนซ้าย) และเพิ่ม Keyframe ที่เฟรม 20 (ขยับแขนขวา) **โปรแกรมจะสร้าง Waypoint ล็อกตำแหน่งเดิมที่เฟรม 10 ให้แขนขวาโดยอัตโนมัติ** ทำให้แขนขวาไม่ขยับก่อนเวลา |
| **วิธีแก้ปัญหา / การทำให้กลับสู่ท่าเริ่มต้น** | หากใช้เฉพาะ Waypoint ต้องคลิกเลเยอร์แขนขวา → ไปที่เฟรม 10 → คลิกขวา Waypoint ที่เฟรม 0 → เลือก **`Duplicate`** เพื่อล็อกท่าเอง | สะดวกกว่ามากสำหรับการขยับหลายชิ้นส่วน และหากต้องการให้เฟรมที่ 30 กลับสู่ท่าเริ่มต้นเหมือนเฟรม 0 ทุกชิ้นส่วน เพียงไปที่หน้าต่าง **Keyframe (รูปกุญแจ)** → เลือกเฟรม 30 → คลิกขวาที่ Keyframe `0f` → เลือก **`Duplicate Keyframe`** |

## ส่วนที่ 5: การสร้างแอนิเมชันให้ตัวละครพูด (Lip-Sync ด้วย Switch Layer) และการสร้างตัวละครเดินด้วยกระดูก (Skeleton & Time Loop) (CLO3, CLO4) ⭐⭐⭐

### 5.1 การทำตัวละครพูดขยับปากตามเสียง (`Group Layers into Switch` — สไลด์หน้า 61–73 — ออกสอบเน้นมาก!) ⭐⭐⭐
จากไฟล์ปฏิบัติการโฟลเดอร์ `talk` (มีไฟล์ใบหน้าขยับปาก `head-1.png` ถึง `head-5.png` และไฟล์เสียง `sound.wav`):
1. นำเข้ารูปใบหน้าทั้ง 5 แบบ (`head-1.png` ถึง `head-5.png`) เข้ามาในโปรแกรม
2. เลือกเลเยอร์ใบหน้าทั้งหมด → คลิกขวา → เลือกคำสั่ง **`Group Layers into Switch`** (สไลด์หน้า 64)
3. เมื่อคลิกที่กลุ่ม `Switch` ในหน้าต่าง **Parameter** จะมีพารามิเตอร์สำคัญชื่อว่า **`Active Layer Name`** ซึ่งใช้กำหนดว่าจะให้แสดงรูปใบหน้าเลเยอร์ใดในขณะนั้น (เช่น `head-1.png`)
4. นำกลุ่ม `Switch` ไปวางประกอบเข้ากับลำตัว (`BODY`)
5. นำเข้าไฟล์เสียงพากย์ด้วย **`File` → `Import` → เลือก `sound.wav`** (จะเกิดเลเยอร์เสียงรูปลำโพงในหน้าต่าง Layers)
6. กดปุ่ม Play ฟังเสียง แล้วสร้าง **`Keyframe`** กำกับไว้ที่จุดเริ่มต้นและจุดสิ้นสุดของแต่ละประโยค (เช่น เริ่มประโยค 1, จบประโยค 1, เริ่มประโยค 2, จบประโยค 2)
7. เปิดโหมด **Turn on animate editing mode** → คลิกเลือกกลุ่ม `Switch` → คลิกเลือกเฟรมต่างๆ ในช่วงระหว่างเริ่มประโยคถึงจบประโยค → เปลี่ยนชื่อรูปใบหน้าในช่อง **`Active Layer Name`** สลับไปมา (`head-1` ถึง `head-5`) เพื่อให้ปากขยับพูดตามเสียง

### 5.2 การสร้างตัวละครเดินด้วยโครงกระดูก (`Skeleton` / Bone Rigging — สไลด์หน้า 74–104 — ออกสอบเน้นมาก!) ⭐⭐⭐
จากไฟล์ปฏิบัติการโฟลเดอร์ `bone` (มีรูปต้นแบบท่าทาง `0.png` และชิ้นส่วนแยกย่อย: `body`, `head`, `upper arm`, `lower arm`, `hand`, `upper leg`, `lower leg`, `foot` แยกซ้าย-ขวา):
1. **การจัดวางชิ้นส่วนตามภาพต้นแบบ (`0.png` — สไลด์หน้า 75–79)**:
   - นำเข้าชิ้นส่วนทั้งหมดและภาพต้นแบบ `0.png`
   - คลิกที่เลเยอร์ `0.png` → ปรับค่า **`Opacity` (ความโปร่งใส) ในหน้าต่าง Parameter ให้เป็น `0.5`** เพื่อใช้เป็นภาพร่างอ้างอิง → เรียงชิ้นส่วนแขน ขา ลำตัว ศีรษะทาบให้ตรงกับ `0.png` → เสร็จแล้วติ๊กซ่อนเลเยอร์ `0.png`
2. **การสร้างชั้นโครงกระดูก (`Skeleton` — สไลด์หน้า 80–81)**:
   - คลิกขวาที่เลเยอร์บนสุด → เลือก **`New Layer` → `Other` → `Skeleton`**
   - **หน้าที่ของจุดควบคุมบนกระดูก (Bone Handles — สไลด์หน้า 80)**:
     - **จุดสีเขียว**: กำหนดจุดเริ่มต้น/จุดหมุนของกระดูก
     - **จุดสีน้ำเงิน**: หมุนปรับมุมของกระดูก
     - **จุดสีส้ม**: ปรับมุมและ **ความยาวของกระดูก**
   - การสร้างกระดูกชิ้นถัดไปที่เชื่อมต่อกัน: คลิกขวาที่กระดูกตั้งต้น → เลือก **`Create Child Bone`** (กระดูก `Child bone` จะขยับตาม `Parent bone` และสามารถหมุนขยับแยกของตัวเองได้ด้วย)
3. **การจัดลำดับโครงสร้างกระดูกที่ถูกต้อง (Bone Hierarchy — สไลด์หน้า 82–84 — ออกสอบเน้น!)**:
   - **กระดูกหลัก (`Parent bone` ตัวแม่สุด)**: วางไว้ที่ **แกนกลางด้านล่าง/พื้น** เพื่อรับผิดชอบการขยับเคลื่อนที่ของทั้งตัวการ์ตูน
   - **ส่วนลำตัว ศีรษะ และแขน**: สร้าง `Child bone` จากแกนกลางขึ้นมาที่ **ลำตัว (`Body`)** → จากกระดูกลำตัว สร้าง `Child bone` แยกไปยัง **ศีรษะ (`Head`)** และ **แขนท่อนบน ➔ แขนท่อนล่าง ➔ มือ** ทั้งสองข้าง
   - **ส่วนขา (ข้อควรระวังในสไลด์หน้า 84!)**: **ส่วนขาควรสร้าง `Child bone` แยกออกมาจาก `Parent bone` ที่แกนกลางโดยตรง** (ไม่ใช่สร้างต่อจากกระดูกลำตัว) ไปยัง **ขาท่อนบน ➔ ขาท่อนล่าง ➔ เท้า** ทั้งสองข้าง
4. **การผูกชิ้นส่วนรูปภาพเข้ากับกระดูก (`Link to Bone` — สไลด์หน้า 85)**:
   - กด `Ctrl` ค้างไว้แล้วคลิกเลือก **เลเยอร์รูปภาพชิ้นส่วน (เช่น `body`)** และ **เลเยอร์ `Skeleton`** พร้อมกัน
   - คลิกที่ **จุดสีเขียว** ของชิ้นส่วนรูปภาพ (`body`) ให้สว่างขึ้น
   - คลิกขวาที่เส้น/จุดของกระดูกท่อนที่ตรงกัน → เลือกคำสั่ง **`Link to Bone`**
5. **การจัดท่าทางการเดินทีละก้าวบนเส้นเวลา (สไลด์หน้า 87–104)**:
   - ลากเส้นประนำสายตา (Guide line) ลงมาจาก **ไม้บรรทัด (`Ruler`)** ด้านบนเพื่อเป็นเส้นระดับพื้นดิน และสร้างวงกลมเล็กๆ มาร์กตำแหน่งส้นเท้า
   - **ก้าวที่ 1 (เฟรม `0f` ถึง `16f`)**: เฟรม `0f` คือท่าเริ่มต้น → เฟรม `16f` สร้าง Keyframe สลับขาและแขนซ้าย-ขวาเมื่อก้าวที่ 1 เสร็จสมบูรณ์พร้อมเลื่อนตัวไปข้างหน้า → ย้อนกลับมาสร้าง Keyframe ที่เฟรมครึ่งทางคือ **เฟรม `8f`** เพื่อดัดเข่าจังหวะยกก้าวผ่านให้ดูสมจริง
   - **ก้าวที่ 2 (เฟรม `16f` ถึง `32f`)**: เมื่อจบก้าวที่ 2 ที่ **เฟรม `32f`** ท่าทางของแขนและขาจะ **กลับมาเหมือนกับท่าเริ่มต้นที่เฟรม `0f` ทุกประการ** จึงใช้วิธีคลิกขวาที่ Keyframe เฟรม `0f` แล้วกด **`Duplicate Keyframe`** มาที่เฟรม `32f` (แล้วสร้าง Keyframe ดัดขาจังหวะก้าวผ่านที่เฟรมครึ่งทางคือ **เฟรม `24f`**)
   - ก้าวที่ 3 (เฟรม `32f` ถึง `48f`): เฟรม `40f` Duplicate มาจากเฟรม `8f`, และเฟรม `48f` Duplicate มาจากเฟรม `16f`

### 5.3 การทำลูปการเดินอัตโนมัติด้วย `Time Loop` (สไลด์หน้า 105–112 — ออกสอบเน้นมาก!) ⭐⭐⭐
แทนที่จะต้องคัดลอก Keyframe ไปเรื่อยๆ เมื่อต้องการให้ตัวละครเดินต่อเนื่องนานๆ สามารถทำ **Walk Cycle (เดินย่ำอยู่กับที่แล้ววนลูปเวลา)** ได้ดังนี้:
1. คลิกเลือกเลเยอร์ `Group` หลักของตัวละคร → ไปที่หน้าต่าง **Parameter** → ขยายหัวข้อ **`Transformation`** → ดูที่บรรทัด **`Offset`** (ซึ่งเก็บค่าการเคลื่อนที่ไปข้างหน้า)
2. ในหน้าต่าง Time Track แถว `Offset` ให้ **คลิกขวาที่ Waypoint ทั้งหมดแล้วเลือก `Remove`** เพื่อลบการเคลื่อนที่ไปข้างหน้าออก (ตัวละครจะเดินก้าวขาอยู่กับที่ในช่วงเฟรม `0f` ถึง `32f`)
3. คลิกขวาที่เลเยอร์ `Group` → เลือก **`New Layer` → `Time` → `Time Loop`** (สไลด์หน้า 108)
4. คลิกที่เลเยอร์ **`Time Loop`** → ในหน้าต่าง Parameter ที่ช่อง **`Duration`** ให้เปลี่ยนค่าเป็น **`31f`** (เนื่องจาก 1 รอบของการก้าวครบซ้าย-ขวาเริ่มที่ `0f` และครบรอบซ้ำท่าเดิมที่ `32f` จึงตั้ง Duration เป็น `31f` เพื่อให้วนลูปอย่างต่อเนื่องไร้รอยต่อ)

## ส่วนที่ 1: สถิติอินเทอร์เน็ต พฤติกรรมผู้ใช้งาน และองค์ประกอบของการสร้างเว็บไซต์ (CLO1, CLO3) ⭐⭐⭐

### 1.1 สถิติผู้ใช้งานอินเทอร์เน็ตและเว็บไซต์ที่สำคัญ (สไลด์หน้า 2–6 — ออกสอบเน้น!) ⭐⭐⭐
1. **จำนวนผู้ใช้งานอินเทอร์เน็ต (DataReportal / We Are Social — สไลด์หน้า 2)**:
   - **ทั่วโลก**: มีผู้ใช้งานอินเทอร์เน็ตประมาณ **5,600 ล้านคน** (คิดเป็นประมาณ **68% ของประชากรโลก**)
   - **ประเทศไทย**: มีผู้ใช้งานอินเทอร์เน็ตมากกว่า **65 ล้านคน** (คิดเป็นประมาณ **90% ของประชากรไทย**)
2. **จำนวนเว็บไซต์และการสืบค้นข้อมูล (สไลด์หน้า 3)**:
   - โลกมีเว็บไซต์ทั้งหมดประมาณ **1.1 – 1.2 พันล้านเว็บไซต์** แต่มีเว็บไซต์ที่ **ยังอัปเดตและใช้งานอยู่จริง (Active) เพียง 17–18%** (ประมาณ **200 ล้านเว็บไซต์**)
   - มีเว็บไซต์เกิดใหม่ประมาณ **250,000 เว็บไซต์ต่อวัน** (เฉลี่ยมีเว็บใหม่เกิดขึ้น **ทุกๆ 3 วินาที**)
   - **`Google.com`** ยังคงเป็นเว็บไซต์ที่มีคนเข้าชมมากที่สุดเป็น **อันดับ 1 ของโลก** (มากกว่า 80,000 ล้านครั้งต่อเดือน หรือมีการค้นหามากกว่า 5 ล้านล้านครั้งต่อปี)
3. **ความสำคัญของเว็บไซต์ต่อธุรกิจและความน่าเชื่อถือ (สไลด์หน้า 4)**:
   - ธุรกิจขนาดเล็ก **71% – 73%** มีเว็บไซต์เป็นของตัวเอง (เพิ่มขึ้นอย่างมากหลังยุค COVID-19)
   - **75% ของผู้ใช้งานประเมินความน่าเชื่อถือของธุรกิจหรือองค์กรจาก "การออกแบบหน้าตาเว็บไซต์" (Website Design)** *(ข้อมูลจาก Stanford Web Credibility Research)*
4. **สถิติการใช้งานผ่านอุปกรณ์พกพา (Mobile Devices) และความเร็วในการโหลด (สไลด์หน้า 5–6 — ออกสอบเน้นมาก!)**:
   - **สัดส่วนการเข้าชมเว็บไซต์แบ่งตามอุปกรณ์ (สไลด์หน้า 5)**:
     - **โทรศัพท์มือถือ (Mobile devices)**: **`50.38%`** (ครองสัดส่วนสูงสุดเป็นอันดับ 1)
     - **คอมพิวเตอร์โน้ตบุ๊ก/พีซี (Laptops/Desktops)**: **`46.51%`**
     - **แท็บเล็ต (Tablets)**: **`3%`**
   - **58%** ของการเข้าชมเว็บไซต์ผ่าน Google มาจากโทรศัพท์มือถือ โดยหมวดหมู่ที่ถูกค้นหาผ่านมือถือสูงสุด ได้แก่:
     1. อาหารและเครื่องดื่ม (**Food & beverage**: **72%**)
     2. **สุขภาพ (Health: `68%`)** และ กีฬา (**Sports: `68%`**)
     3. ข่าวและสื่อ (**News and Media: 64%**)
     4. ไลฟ์สไตล์ (**Lifestyle: 62%**)
   - **สถิติพฤติกรรมผู้ใช้เมื่อเว็บโหลดช้า (สไลด์หน้า 6)**: **53% ของผู้ใช้งานผ่านโทรศัพท์มือถือจะกดออกจากเว็บไซต์ทันที หากเว็บไซต์ใช้เวลาโหลดนานเกินกว่า `3 วินาที`!**
   - **57%** ของผู้ใช้งานจะไม่แนะนำธุรกิจที่มีการออกแบบเว็บไซต์บนมือถือไม่ดี (**Poorly designed website on mobile** — สไลด์หน้า 20)

### 1.2 สิ่งที่จำเป็นต้องมีในการสร้างและเผยแพร่เว็บไซต์ 3 ประการ (สไลด์หน้า 7 — ออกสอบแน่นอน!) ⭐⭐⭐
ในการสร้างและนำเว็บไซต์ขึ้นเผยแพร่บนเครือข่ายอินเทอร์เน็ต จำเป็นต้องมีองค์ประกอบหลัก **3 ส่วน** คือ:
1. **ตัวเว็บไซต์ (Website / Web Files & Database)**
2. **พื้นที่เก็บเว็บไซต์บนอินเทอร์เน็ต (Web Hosting)**
3. **ชื่อเว็บไซต์ หรือ โดเมนเนม (Domain Name)**

### 1.3 เปรียบเทียบวิธีการสร้างเว็บไซต์ทั้ง 3 วิธี (สไลด์หน้า 8–14) ⭐⭐⭐

| วิธีการสร้างเว็บไซต์ | ลักษณะและตัวอย่างเครื่องมือ | ข้อดี | ข้อจำกัด |
| :--- | :--- | :--- | :--- |
| **1. การสร้างด้วยการเขียนโค้ดภาษา HTML และภาษาอื่นๆ** *(สไลด์หน้า 9–10)* | เขียนชุดคำสั่ง HTML/CSS/JS เองโดยตรง (ปัจจุบันมักใช้ในการตกแต่งหน้าเว็บเพิ่มเติม) | **ได้รูปแบบของเว็บไซต์ตรงตามที่ต้องการทุกประการ** | ต้องมีทักษะความชำนาญในการเขียนโปรแกรมสูง และ **ใช้เวลานาน** |
| **2. การใช้บริการสร้างเว็บไซต์ของ Web Hosting (Website Builders)** *(สไลด์หน้า 11–12)* | เช่น **Wix**, **Google Sites** | **เหมาะสำหรับผู้เริ่มต้น**, ใช้เวลาสร้างน้อย, ค่าใช้จ่ายต่ำหรือใช้ได้ฟรี | **ปรับเปลี่ยนรูปแบบนอกเหนือจากแม่แบบ (Template) ที่ผู้ให้บริการกำหนดไว้ได้ไม่มาก** |
| **3. การใช้โปรแกรมสำเร็จรูปในการสร้างเว็บไซต์** *(สไลด์หน้า 13–14)* | แบ่งเป็น 2 กลุ่มย่อย:<br>• **โปรแกรมที่มีลิขสิทธิ์**: เช่น **Adobe Dreamweaver** (ประมาณ 876–1,315 บาท/เดือน)<br>• **โปรแกรมฟรีประเภท CMS**: เช่น **WordPress, Joomla, Drupal** | • *โปรแกรมมีลิขสิทธิ์*: สร้างเว็บได้สะดวกรวดเร็ว<br>• *โปรแกรมฟรี (CMS)*: ไม่มีค่าซอฟต์แวร์ มีระบบจัดการเนื้อหาสำเร็จรูป | • *โปรแกรมมีลิขสิทธิ์*: ผู้ใช้ต้องมีความรู้คอมพิวเตอร์ระดับหนึ่ง และ **มีค่าใช้จ่ายค่าลิขสิทธิ์**<br>• *โปรแกรมฟรี (CMS)*: **ปรับแต่งการแสดงผลอย่างอิสระได้ยากกว่าการเขียนโค้ดเอง** |

## ส่วนที่ 2: ระบบจัดการเนื้อหาเว็บไซต์ (CMS) และ Responsive Design (CLO1, CLO3) ⭐⭐⭐

### 2.1 ความหมายและส่วนแบ่งตลาดของ CMS (Content Management System) (สไลด์หน้า 15–19 — ออกสอบเน้นมาก!) ⭐⭐⭐
- **CMS (Content Management System)** คือ ระบบจัดการเนื้อหาของเว็บไซต์ที่ช่วยลดทรัพยากรในการพัฒนาและบริหารจัดการเว็บไซต์ โดย **ผู้ใช้งานไม่จำเป็นต้องเขียนโค้ดเอง** และรองรับการทำ **Responsive Design**
- **สถิติส่วนแบ่งตลาด CMS ทั่วโลก (ข้อมูลจาก W3Techs — สไลด์หน้า 17–19)**:
  - เว็บไซต์ทั่วโลกอีกประมาณ **`28.6%`** ไม่ได้ใช้ระบบ CMS ที่ตรวจจับได้
  - **อันดับ 1 ของโลกคือ `WordPress`**:
    - มีผู้ใช้งานคิดเป็น **`43.3%` ของเว็บไซต์ทั้งหมดทั่วโลก**
    - คิดเป็นส่วนแบ่งตลาดสูงถึง **`60.7%` ของเว็บไซต์ที่ใช้ระบบ CMS ทั้งหมด**
    - และในกลุ่ม **1,000 เว็บไซต์ยอดนิยมอันดับต้นของโลก (Top 1,000 websites)** มีการใช้ WordPress สูงถึง **`48.9%`**
  - อันดับรองลงมาในภาพรวม ได้แก่ **Shopify** (4.8% ของเว็บทั้งหมด / 6.8% ของ CMS), **Wix** (4.1% / 5.7%), **Squarespace** (2.4% / 3.4%)
- **เปรียบเทียบ 3 โปรแกรม Open-Source CMS ยอดนิยม (`WordPress` vs `Joomla` vs `Drupal` — สไลด์หน้า 18–19)**:

| ลำดับ | Open-Source CMS | สัดส่วนต่อเว็บทั้งหมดทั่วโลก | ส่วนแบ่งตลาดเฉพาะในกลุ่ม CMS | แนวโน้มและกลุ่มเว็บไซต์ที่นิยมนำไปใช้ (ตามสไลด์หน้า 18–19) |
| :---: | :--- | :---: | :---: | :--- |
| **1** | **WordPress** | **`43.3%`** | **`60.7%`** | คงที่อยู่ในระดับสูง (43–44%) และได้รับความนิยมสูงสุดในทุกระดับขนาดเว็บไซต์ |
| **2** | **Joomla** | **`1.4%`** | **`2.0%`** | แนวโน้มลดลงอย่างต่อเนื่อง (จาก 1.6% เหลือ 1.4%) และถูกใช้งานน้อยลงในกลุ่มเว็บไซต์ยอดนิยม (เหลือเพียง 0.6–0.8% ในกลุ่ม Top websites) |
| **3** | **Drupal** | **`0.8%`** | **`1.1%`** | แนวโน้มภาพรวมลดลงเล็กน้อย (จาก 0.9% เหลือ 0.8%) **แต่ได้รับความนิยมสูงในกลุ่มเว็บไซต์ขนาดใหญ่ที่มีการเข้าชมสูง** (มีสัดส่วนสูงถึง **6–7%** ในกลุ่ม Top 100,000 และ Top 10,000 เว็บไซต์ของโลก) |

### 2.2 การออกแบบเว็บไซต์แบบ `Responsive Design` (สไลด์หน้า 20) ⭐⭐⭐
- **Responsive Design** คือ การออกแบบเว็บไซต์ให้สามารถ **ปรับขนาดและจัดวางโครงสร้างการแสดงผลให้เหมาะสมกับขนาดหน้าจอของอุปกรณ์ทุกชนิดโดยอัตโนมัติ** (ทั้ง Desktop, Tablet และ Mobile)
- มีความสำคัญอย่างยิ่งต่อสื่อสุขภาพ เพราะผู้ใช้งานมากกว่าครึ่งเข้าเว็บผ่านมือถือ และ **57% ของผู้ใช้จะไม่แนะนำธุรกิจที่หน้าเว็บแสดงผลบนมือถือได้ไม่ดี**

## ส่วนที่ 3: พื้นที่เก็บเว็บไซต์ (Web Hosting) และชื่อโดเมนเนม (Domain Name) (CLO1, CLO2, CLO3) ⭐⭐⭐

### 3.1 การเลือกใช้บริการ Web Hosting: แบบฟรี VS แบบเสียค่าใช้จ่าย (สไลด์หน้า 21–29, 53) ⭐⭐⭐
- **หลักเกณฑ์ในการพิจารณาเลือก Web Hosting (สไลด์หน้า 25)**:
  1. ขนาดพื้นที่จัดเก็บข้อมูล (Disk Space)
  2. บริการจดชื่อโดเมนเนมฟรีหรือไม่
  3. รองรับการรับ-ส่งไฟล์ผ่านระบบ **FTP (File Transfer Protocol)** หรือไม่
  4. มีโฆษณาแฝงหรือไม่
  5. ความเสถียรและความเร็วในการให้บริการ
  6. ความง่ายในการใช้งานระบบจัดการ (**Control Panel**)
  7. ปริมาณการรับ-ส่งข้อมูลสูงสุด (**Data Transfer / Bandwidth Traffic**)
- **ข้อจำกัดของ `Free Web Hosting` (เช่น `InfinityFree`, `AwardSpace` — สไลด์หน้า 26)**:
  1. **พื้นที่จัดเก็บข้อมูลน้อย**
  2. **มักมีโฆษณาแฝง**
  3. **ไม่อนุญาตให้อัปโหลดไฟล์บางประเภท**
  4. มักไม่มีโปรแกรมช่วยในการอัปโหลดไฟล์ที่สะดวก
  5. การให้บริการค่อนข้างช้า
  6. บางแห่งไม่มีระบบจัดการฐานข้อมูล หรือ **ไม่รองรับภาษาไทย**
- **สเปกของ `AwardSpace` แบบใช้งานฟรี (`Free Plan`) ที่ใช้ในปฏิบัติการ (สไลด์หน้า 53 — ระวังออกสอบ!)**:
  - พื้นที่เก็บข้อมูล (`Disk Space`): **`1 GiB`** *(หมายเหตุในสไลด์หน้า 53: **`1 GiB = 1024³ bytes`** ซึ่งมีค่ามากกว่า **`1 GB = 1000³ bytes`**)*
  - ปริมาณการรับส่งข้อมูล (`Traffic`): **`5 GiB`**
  - จำนวน `Domains`: **`1` โดเมน** และ **`Subdomains` สูงสุด `3` ซับโดเมน**
  - ฐานข้อมูล **`MySQL Databases`: `1` ฐานข้อมูล** (ส่วน `PostgreSQL`: `0`)

### 3.2 กฎการตั้งชื่อ `Domain Name` และประเภทของโดเมน (สไลด์หน้า 30–36 — ออกสอบเน้นมาก!) ⭐⭐⭐
- **หน้าที่ของ Domain Name**: เป็นระบบชื่อที่ใช้เรียกแทนหมายเลข **IP Address** (เช่น `202.28.75.15`) เพื่อให้มนุษย์จดจำและเข้าถึงเว็บไซต์ได้ง่าย
- **กฎเหล็ก 3 ข้อในการตั้งชื่อ Domain Name (สไลด์หน้า 32 — ออกสอบแน่นอน!)**:
  1. **ประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข และเครื่องหมายขีดกลาง (`-` / Hyphen) เท่านั้น**
  2. **ห้ามมีช่องว่าง (Space) หรือเครื่องหมายวรรคตอนอื่นๆ เด็ดขาด** (เช่น ห้ามใช้ `_`, `@`, `/`, `.` คั่นกลางชื่อ)
  3. **ต้องไม่ซ้ำกับชื่อโดเมนเนมที่มีผู้อื่นจดทะเบียนไว้แล้ว**
- **การจดโดเมนเนมแบบเสียค่าใช้จ่าย vs แบบฟรี (สไลด์หน้า 33–36)**:
  - **โดเมนสากลทั่วไป (`.com`, `.net`, `.org`)**: ราคาประมาณ 280–350 บาท/ปี **สามารถจดทะเบียนได้ทันทีโดยไม่ต้องใช้เอกสารยืนยันตัวตนของหน่วยงาน**
  - **โดเมนภายใต้ `.th` ของประเทศไทย (`.co.th`, `.or.th`, `.go.th`, `.ac.th`, `.in.th`)**: **ต้องใช้เอกสารหลักฐานทางราชการหรือเอกสารจดทะเบียนนิติบุคคลประกอบการขอจดทะเบียน**
  - **โดเมนเนมฟรี (`Free Domain Name` — สไลด์หน้า 36)**: มักอยู่ในรูปแบบของ **`Subdomain` (โดเมนย่อย)** ที่พ่วงท้ายด้วยชื่อของผู้ให้บริการ เช่น `www.silpakorn.eu.pn`, `www.healthinformatics.wordpress.com`, หรือ `xxx.atwebpages.com` ซึ่งมีข้อเสียคือ **ชื่อยาวและจดจำได้ยากกว่าโดเมนหลัก**

## ส่วนที่ 4: ความรู้เบื้องต้นเกี่ยวกับ WordPress และความแตกต่างระหว่าง WordPress.org VS WordPress.com (CLO1, CLO3) ⭐⭐⭐

### 4.1 ประวัติ โครงสร้างทางเทคนิค และจุดเด่นของ WordPress (สไลด์หน้า 37–41 — ออกสอบเน้น!) ⭐⭐⭐
- **วันที่เปิดตัวครั้งแรก**: **`27 พฤษภาคม ค.ศ. 2003` (`27/05/2003`)** (พัฒนาโดย Mike Little และ Matt Mullenweg)
- **ภาษาโปรแกรมและฐานข้อมูลที่ใช้ (สไลด์หน้า 38 — ออกสอบเน้น!)**:
  - เขียนด้วยภาษา **`PHP`**
  - ทำงานร่วมกับฐานข้อมูล **`MySQL`** หรือ **`MariaDB`**
- **ข้อดีของ WordPress (สไลด์หน้า 41)**:
  1. เป็น **Open source (ใช้งานฟรี)**
  2. **ติดตั้งง่าย** (`Easy to install`)
  3. มี **Widgets และ Plugins** ให้เลือกใช้งานจำนวนมาก
  4. มี **ความปลอดภัยสูง** (`High security`)

### 4.2 ตารางเปรียบเทียบ `WordPress.org` VS `WordPress.com` (สไลด์หน้า 42–45 — ออกสอบแน่นอน!) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | `WordPress.org` (Self-hosted WordPress) | `WordPress.com` (Hosted Service) |
| :--- | :--- | :--- |
| **ลักษณะการให้บริการ** | ให้ **ดาวน์โหลดไฟล์โปรแกรม WordPress ไปติดตั้งเองบน Web Hosting ของผู้ใช้งาน** | เป็น **บริการแบบครบวงจรในที่เดียว** (รวมเครื่องมือสร้างเว็บ + ติดตั้งสำเร็จรูป + โฮสติ้ง + โดเมน + การเผยแพร่) |
| **ข้อดี (Pros)** | 1. **มีอิสระเต็มที่ในการปรับแต่ง แก้ไข เพิ่ม หรือลบ Theme, Plugin และโค้ดโปรแกรม**<br>2. **ไม่มีโฆษณาแฝง** จากผู้ให้บริการแพลตฟอร์ม | 1. **ไม่ต้องดูแลเซิร์ฟเวอร์ การอัปเดต การสำรองข้อมูล (Backup) หรือความปลอดภัยเอง**<br>2. เริ่มต้นสร้างเว็บไซต์ได้รวดเร็ว และมีแพ็กเกจฟรีให้ทดลองใช้ |
| **ข้อจำกัด (Cons)** | 1. **ไม่สะดวกสำหรับผู้ที่ไม่มีพื้นฐานทางเทคนิค** (ต้องหาโฮสติ้งและติดตั้งเอง)<br>2. **มีค่าใช้จ่ายในการเช่า Web Hosting และจด Domain Name** | 1. **แพ็กเกจฟรีมีโฆษณาแฝง** และได้ชื่อเว็บเป็น Subdomain<br>2. **ไม่สามารถปรับแต่งหรือติดตั้ง Theme/Plugin เสริมได้อย่างอิสระ** หากไม่อัปเกรดแพ็กเกจ<br>3. แพ็กเกจเสียเงิน (`Personal`, `Premium`, `Business`, `Commerce`) มีราคาค่อนข้างสูง |

## ส่วนที่ 5: การติดตั้ง WordPress บน AwardSpace การตั้งค่าเริ่มต้น และการปรับแต่ง Theme (CLO3, CLO4) ⭐⭐⭐

### 5.1 ขั้นตอนการติดตั้ง WordPress บนโฮสติ้ง `AwardSpace` และการเข้าสู่ระบบ (สไลด์หน้า 46–69) ⭐⭐⭐
1. สมัครสมาชิกที่ `www.awardspace.com` → เข้าสู่ระบบ Control Panel
2. **สร้าง Subdomain ฟรี**: ไปที่ `Hosting Tools` → `Website Manager` → **`Domain Manager`** → เลือก **`Create a Free Subdomain`** (เช่น ได้ชื่อเว็บลงท้ายด้วย `.atwebpages.com`)
3. **ติดตั้งโปรแกรม WordPress อัตโนมัติ**: ไปที่ `Hosting Tools` → **`Zacky App Installer`** → เลือก Subdomain ที่สร้างไว้ → เลือกติดตั้ง **`WordPress`** → กำหนดชื่อเว็บไซต์ (`Website Title`), ชื่อผู้ดูแลระบบ (`Admin Username`), รหัสผ่าน (`Admin Password`), และอีเมล → คลิก **`Install Application`**
4. **URL สำหรับเข้าใช้งานเว็บไซต์ 2 ส่วน (สไลด์หน้า 62–64 — ออกสอบเน้น!)**:
   - **ส่วนหน้าบ้าน (`Front-end` สำหรับผู้เข้าชมทั่วไป)**: เข้าผ่าน **`http://ชื่อเว็บไซต์`** (เช่น `http://healthmedia.atwebpages.com`)
   - **ส่วนหลังบ้าน (`Back-end / Dashboard` สำหรับผู้ดูแลระบบ)**: เข้าผ่าน **`http://ชื่อเว็บไซต์/wp-admin/`**
5. **การตั้งค่าพื้นฐานหลังติดตั้ง (`Settings` → `General` — สไลด์หน้า 66–69)**:
   - ปรับเขตเวลา (**`Timezone`**) ให้ตรงกับประเทศไทยคือ **`UTC+7`**
   - ปรับรูปแบบการแสดงผลวันที่ (`Date Format`) และเวลา (`Time Format`) → คลิก **`Save Changes`**

### 5.2 การเปลี่ยน ติดตั้ง และปรับแต่ง `Theme` (สไลด์หน้า 70–99) ⭐⭐⭐
1. **การเปลี่ยนและติดตั้ง Theme ใหม่ (`Dashboard` → `Appearance` → `Themes` → `Add Theme`)**:
   - **วิธีที่ 1 (ค้นหาจากคลัง WordPress)**: พิมพ์ชื่อ Theme ในช่องค้นหา (เช่น `Astra`, `Karuna`) → คลิก **`Install`** → คลิก **`Activate`** เพื่อเปิดใช้งาน
   - **วิธีที่ 2 (อัปโหลดไฟล์ `.zip`)**: ดาวน์โหลดไฟล์ Theme นามสกุล `.zip` มาจากเว็บไซต์ `wordpress.org/themes` → คลิกปุ่ม **`Upload Theme`** ด้านบน → เลือกไฟล์ `.zip` → คลิก `Install Now` → คลิก **`Activate`**
2. **การปรับแต่งหน้าตาเว็บไซต์ (`Appearance` → `Customize` — สไลด์หน้า 83–99 — ออกสอบเน้น!)**:
   - **`Site Identity` (ข้อมูลอัตลักษณ์ของเว็บไซต์)**:
     - **`Logo`**: อัปโหลดรูปภาพโลโก้ของเว็บไซต์ (`Select logo`)
     - **`Site Title`**: ชื่อหลักของเว็บไซต์
     - **`Tagline`**: คำขวัญหรือคำอธิบายสั้นๆ ของเว็บไซต์
     - **`Site Icon` (หรือ Favicon)**: ไอคอนขนาดเล็กที่แสดงบนแท็บของเว็บเบราว์เซอร์ (**ต้องเป็นรูปสี่เหลี่ยมจัตุรัสขนาดอย่างน้อย `512 × 512 pixels`** เช่น ดาวน์โหลดไอคอนจาก `flaticon.com`)
   - **`Colors`**: เปลี่ยนสีข้อความส่วนหัว (`Header Text Color`) และสีพื้นหลัง (`Background Color`)
   - **`Header Image`**: เปลี่ยนรูปภาพแบนเนอร์ขนาดใหญ่ด้านบนของเว็บไซต์
   - **การบันทึกการปรับแต่ง**: เมื่อแก้ไขในหน้า Customize เสร็จแล้ว ต้องคลิกปุ่ม **`Publish`** มุมซ้ายบนเสมอ

## ส่วนที่ 6: การจัดการเนื้อหาเว็บไซต์: ความแตกต่างระหว่าง Post VS Page (ออกสอบแน่นอน!) ⭐⭐⭐

### 6.1 ตารางเปรียบเทียบความแตกต่างระหว่าง `Post` และ `Page` (สไลด์หน้า 100–126) ⭐⭐⭐

| ประเด็นเปรียบเทียบ | `Post` (บทความ / ข่าวสาร) | `Page` (หน้าเว็บคงที่) |
| :--- | :--- | :--- |
| **ลักษณะเนื้อหาที่เหมาะสม** | **เนื้อหาที่มีความเคลื่อนไหว เปลี่ยนแปลงตามเวลา หรืออัปเดตเป็นประจำ** เช่น ข่าวประชาสัมพันธ์, บทความสุขภาพ, รีวิว, กิจกรรมใหม่ๆ | **เนื้อหาที่คงที่ (Static Content) ไม่ค่อยเปลี่ยนแปลงบ่อย** เช่น หน้าแรก (`Home`), เกี่ยวกับเรา (`About Us`), ติดต่อเรา (`Contact Us`), โครงสร้างองค์กร |
| **การจัดหมวดหมู่และคำค้น** | **มีการจัดหมวดหมู่ด้วย `Categories` (หมวดหมู่หลัก/หมวดหมู่ย่อย) และ `Tags` (ป้ายกำกับ/คำสำคัญ)** *(ค่าเริ่มต้นของหมวดหมู่คือ `Uncategorized`)* | **ไม่มี `Categories` และไม่มี `Tags`** (แต่สามารถจัดลำดับชั้นเป็นหน้าหลัก `Parent Page` และหน้าย่อย `Child Page` ได้) |
| **การเรียงลำดับการแสดงผล** | แสดงผลเรียงตามลำดับเวลา (**เนื้อหาที่โพสต์ล่าสุดจะแสดงอยู่ด้านบนสุด — Reverse Chronological Order**) และมักแสดงในหน้า Feed ข่าวสารอัตโนมัติ | **เมื่อสร้างเสร็จจะยังไม่ปรากฏบนหน้าเว็บไซต์โดยอัตโนมัติ** จนกว่าผู้ดูแลจะนำไปผูกเข้ากับ **เมนู (`Menu`)** หรือกำหนดให้เป็นหน้าแรก |
| **การแสดงชื่อผู้เขียน วันที่ และความคิดเห็น** | แสดง **ชื่อผู้เขียน (Author)**, **วันที่เผยแพร่ (Published Date)** และมัก **เปิดให้ผู้อ่านแสดงความคิดเห็น (`Comments`)** ได้ | มัก **ไม่แสดงวันที่และชื่อผู้เขียน** และโดยทั่วไปจะ **ปิดช่องแสดงความคิดเห็น** |

### 6.2 ฟีเจอร์สำคัญในการจัดการ `Post` (สไลด์หน้า 102–120) ⭐⭐
- **การจัดการหมวดหมู่ (`Posts` → `Categories`)**:
  - สามารถสร้างหมวดหมู่หลัก และสร้าง **หมวดหมู่ย่อย (Subcategory)** ได้โดยเลือกหมวดหมู่แม่ในช่อง **`Parent Category`**
- **การตั้งค่าการมองเห็น (`Visibility`) และการตั้งเวลาเผยแพร่ (สไลด์หน้า 115–119)**:
  - **`Public`**: ทุกคนเข้าชมได้ (สามารถติ๊ก `Stick to the top of the blog` เพื่อปักหมุดบทความไว้บนสุดได้)
  - **`Private`**: เฉพาะผู้ดูแลระบบและบรรณาธิการที่เข้าสู่ระบบแล้วเท่านั้นที่มองเห็น
  - **`Password Protected`**: ต้องกรอกรหัสผ่านที่กำหนดไว้จึงจะเปิดอ่านบทความได้
  - **การตั้งเวลาโพสต์ล่วงหน้า (`Publish` → กำหนดวันและเวลาในอนาคต)**: ปุ่มด้านบนจะเปลี่ยนเป็นคำว่า **`Schedule`**
- **การแก้ไขข้อมูลเบื้องต้นอย่างรวดเร็ว (`Quick Edit` — สไลด์หน้า 120)**:
  - ในหน้ารายการ `All Posts` สามารถคลิก **`Quick Edit`** เพื่อเปลี่ยนชื่อเรื่อง หมวดหมู่ ป้ายกำกับ (Tags) สถานะ หรือรหัสผ่านได้อย่างรวดเร็วโดยไม่ต้องเปิดเข้าหน้าแก้ไขเนื้อหาเต็ม

## ส่วนที่ 7: การสร้างระบบเมนูนำทาง (Menus) และการกำหนดหน้าแรกของเว็บไซต์ (Custom Homepage & Query Loop) (CLO3, CLO4) ⭐⭐⭐

### 7.1 การสร้างเมนูหลักและเมนูย่อย (`Menus` — สไลด์หน้า 127–136 — ออกสอบเน้น!) ⭐⭐⭐
1. ไปที่ `Appearance` → `Customize` → **`Menus`** → คลิก **`Create New Menu`**
2. ตั้งชื่อเมนู (เช่น `Main Menu`) และติ๊กเลือก **ตำแหน่งที่จะแสดงเมนู (`Menu Location` เช่น `Header` / `Top Menu` ซึ่งขึ้นอยู่กับแต่ละ Theme)** → คลิก `Next`
3. คลิกปุ่ม **`+ Add Items`** เพื่อเลือกสิ่งที่ต้องการนำมาใส่ในเมนู ซึ่งใส่ได้ทั้ง **`Pages`** (หน้าเว็บ), **`Posts`** (บทความ), **`Categories`** (หมวดหมู่), **`Tags`** (ป้ายกำกับ), และ **`Custom Links`** (ลิงก์ไปยังเว็บไซต์ภายนอก)
4. **วิธีทำเมนูย่อย (Submenu / Drop-down menu — สไลด์หน้า 134 — ออกสอบเน้นมาก!)**:
   - ในรายการเมนู ให้ **คลิกเมาส์ซ้ายค้างที่รายการเมนูที่ต้องการให้เป็นเมนูย่อย แล้วลากเยื้องไปทางด้านขวาเล็กน้อย (`Drag slightly to the right`)** ให้อยู่เยื้องใต้เมนูหลักที่ต้องการ → จากนั้นคลิก **`Publish`**

### 7.2 การสร้างหน้าแรกแบบกำหนดเอง (`Static Homepage`) และการกรองข่าวด้วย `Query Loop` (สไลด์หน้า 137–149 — ออกสอบเน้นมาก!) ⭐⭐⭐
- **ปัญหาของค่าเริ่มต้น**: โดยปกติหน้าแรกของ WordPress จะแสดงบทความ (`Posts`) ทั้งหมดทุกหมวดหมู่ปนกันเรียงตามเวลาล่าสุด
- **ขั้นตอนการสร้างหน้าแรก (`Home`) ให้แสดงเฉพาะบทความที่ต้องการ**:
  1. สร้างหน้าเว็บใหม่ที่เมนู `Pages` → `Add New` (ตั้งชื่อว่า `หน้าแรก` หรือ `Home`)
  2. เพิ่มบล็อก **`Query Loop`** ลงในหน้าเพจ → เลือกรูปแบบการจัดวาง (`Choose pattern`) → คลิก `Edit pattern`
  3. **การกรองให้แสดงเฉพาะบทความที่ติดป้ายกำกับ (`Tags`) หรือหมวดหมู่ที่ต้องการ (สไลด์หน้า 142–145)**:
     - คลิกที่บล็อก `Query Loop` → ในแถบตั้งค่าบล็อกด้านขวา ไปที่หัวข้อ **`Filters`** → คลิกปุ่ม **`+`** → เลือก **`Taxonomies`**
     - ในช่อง **`Tags`** (หรือ `Categories`) ให้พิมพ์ชื่อป้ายกำกับของเนื้อหาที่ต้องการนำมาแสดงในหน้าแรก เช่น พิมพ์คำว่า **`ข่าว`** → คลิก `Publish` หน้าเพจ
  4. **การตั้งค่าให้เพจที่สร้างกลายเป็นหน้าแรกสุดของเว็บไซต์ (`Homepage Settings` — สไลด์หน้า 146–149)**:
     - ไปที่ `Appearance` → `Customize` → **`Homepage Settings`**
     - เปลี่ยนตัวเลือกภายใต้ *"Your homepage displays"* จาก `Your latest posts` เป็น **`A static page`**
     - ในช่อง **`Homepage`** ให้เลือกหน้าเพจ `หน้าแรก` ที่สร้างไว้ → คลิก **`Publish`**

## ส่วนที่ 8: การใช้งาน Widgets และการติดตั้ง/ถอนการติดตั้ง Plugins (CLO1, CLO3, CLO4) ⭐⭐⭐

### 8.1 ความหมายและการจัดการ `Widgets` (สไลด์หน้า 150–159) ⭐⭐⭐
- **Widgets & Plugins**: คือโปรแกรมขนาดเล็กที่ช่วยเพิ่มฟีเจอร์ ความสามารถ และองค์ประกอบการแสดงผลให้กับเว็บไซต์ WordPress (มีทั้งแบบฟรีและเสียค่าใช้จ่าย)
- **การจัดการ `Widgets` (`Appearance` → `Widgets`)**:
  - ใช้สำหรับใส่องค์ประกอบเสริมไว้ตามพื้นที่รอบข้างของเว็บไซต์ที่ Theme กำหนดไว้ เช่น **`Sidebar` (แถบด้านข้าง)**, `Full-Width Header`, `Full-Width Footer`, หรือ **`Footer 1–4` (ส่วนท้ายเว็บไซต์)**
  - **วิธีเพิ่ม Widget**: คลิกปุ่ม **`+`** (`Add block` → `Browse all`) ในส่วนพื้นที่ที่ต้องการ → เลือก Widget เช่น `Search` (ช่องค้นหา), `Latest Posts` (บทความล่าสุด), `Calendar` (ปฏิทิน), `Categories List` (รายการหมวดหมู่), หรือ `Custom HTML` → คลิก **`Update`**
  - **วิธีลบ Widget ที่ไม่ต้องการ**: คลิกที่บล็อก Widget นั้น → คลิกไอคอนจุดสามจุด (`Options`) → เลือก **`Remove ...`** → คลิก **`Update`**

### 8.2 การติดตั้งและการลบ `Plugins` อย่างถูกวิธี (สไลด์หน้า 160–166 — ออกสอบแน่นอน!) ⭐⭐⭐
- **การติดตั้ง Plugin ใหม่ (`Plugins` → `Add Plugin`) ทำได้ 2 วิธี**:
  1. **ค้นหาจากคลังของ WordPress**: พิมพ์คำค้นในช่อง Search plugins (เช่น `Classic Editor`) → คลิก **`Install Now`** → เมื่อติดตั้งเสร็จต้องคลิกปุ่ม **`Activate`** เพื่อเปิดใช้งาน
  2. **อัปโหลดไฟล์ `.zip` (`Upload Plugin`)**: คลิกปุ่ม **`Upload Plugin`** ด้านบน → เลือกไฟล์ `.zip` ของปลั๊กอินที่ดาวน์โหลดมา → คลิก `Install Now` → คลิก **`Activate`**
- **ขั้นตอนการลบ (Uninstall) Plugin ออกจากเว็บไซต์อย่างถูกวิธี 2 ขั้นตอน (สไลด์หน้า 165–166 — ออกสอบเน้นมาก!)**:
  - ไปที่เมนู `Plugins` → **`Installed Plugins`**
  - **ไม่สามารถกดลบ (`Delete`) ได้ทันทีขณะที่ปลั๊กอินยังทำงานอยู่!** ต้องทำตามลำดับ 2 ขั้นตอนดังนี้:
    1. **ขั้นตอนที่ 1**: คลิก **`Deactivate`** เพื่อปิดการทำงานของ Plugin นั้นก่อน
    2. **ขั้นตอนที่ 2**: เมื่อสถานะปิดการทำงานแล้ว จึงคลิกปุ่ม **`Delete`** เพื่อลบออกจากเว็บไซต์
